# 常见问题与排查

先分清问题发生在哪一层：客户端登录、账号权益、插件安装、外部服务连接，还是某次任务的输入与产物。一次任务失败，不代表前面已经完成的分析和文件都需要重做。

## 登录与额度

### 点击登录后没有回到客户端怎么办

客户端会打开系统浏览器完成账号授权，再等待登录结果。先确认浏览器中的授权流程已经完成，客户端仍处于登录等待状态，网络没有拦截相关连接。仍未登录时重新发起一次，不要把网页密码或登录令牌粘贴到聊天里。

具体步骤见[账号与模型](/start/03-model-account)。如果涉及企业账号归属、账号停用或设备限制，向管理员提供错误提示和发生时间，不要公开凭据。

### 在哪里查看余额和用量

从客户端账号菜单进入“用户中心”：在“钱包”查看余额、充值及支付记录，在“用量”查看请求与退费记录。充值方式和可购买项目取决于服务端配置；若提示管理员尚未配置充值档位或支付方式，需要联系管理员处理。

支付完成后应核对订单状态与钱包余额。余额未变时先查支付记录，不连续重复付款。不要把“任务没有返回答案”直接认定为没有计费或必然全额退费。

### 为什么输入框下拉菜单只有思考强度选项？

Kayak 采用专属的模型底座支持办案，输入框下拉菜单中仅提供**思考强度**调节（如常规思考与深度思考），无需切换模型。承办人员可根据具体案情复杂度选择思考深度（复杂争议或文书起草推荐深度思考），无需在多个模型列表中切换。

## 插件与外部服务

### 执行事务插件需要手动安装吗？

不需要。Kayak 法律版已在出厂时预置了“执行事务”核心能力底座，客户端启动时会自动完成部署并默认启用，无需前往插件市场手动搜索或手动安装。若在侧栏“扩展”中看到不可停用或卸载，属于出厂预置的核心能力，并非客户端故障。

安装包、启用状态和服务授权是不同环节。已经安装但调用失败时，继续检查 Kayak 登录状态、连接状态和账号服务权限。参见[插件配置](/start/04-plugin-activation)。

### 插件提示未授权或连接失败怎么办

先保留完整错误提示，再按顺序检查：

1. 当前 Kayak 账号是否已登录，是否需要重新授权。
2. 当前企业或设备是否具有该插件和服务的使用权限。
3. “扩展”中插件是否安装、启用并完成所需配置。
4. 网络是否允许连接对应服务。

401 或 403 可能分别涉及凭据、设备绑定或服务权限，不能统一归为“余额不足”。只提供错误信息与必要的诊断记录，不把包含密钥的配置发到群聊。

### 企查查为什么还要求配置

企查查使用你自己的企查查服务和 API Key，不与 Kayak 登录、钱包余额自动互通。在“扩展”中打开企查查插件，按照安装或待配置提示填写所需密钥。

历史档案、法规、案例和文档等可选服务不是默认全部开通。应按具体错误检查 Key、服务权限、使用约定和网络。没有查到记录，只能说明本次查询范围内未见结果，不能认定企业没有风险。详见[企查查使用说明](/workflows/execution-audit/13-qcc-enterprise-data)。

## 材料与读取

### 扫描件能否全部在本地识别

不能据此作保证。当前文档读取工具在必要时可能调用远程 OCR，且未必逐次弹出上传确认。若材料不允许外传，应在任务开始前限制为本地读取并确认运行环境符合要求；不能读取时让助手列出页面并停止，不自动更换外部服务。

停止任务也不能撤回已经发送的数据。参见[安全边界](/start/basics/07-security-boundary)。

### 文件太多或读取不全怎么办

先让助手列出实际收到和读到的文件，再按材料类型、时间段或争点分批处理。对未读取页、加密文件、破损文件和低清晰度扫描件单列清单，不将“未读到”改写成“材料不存在”。提供清晰副本后，可以在原任务继续。

### 材料相互矛盾或信息缺失怎么办

指出冲突位置及各自来源，说明哪项已经核实，哪些仍有争议。姓名、账号、金额和日期未知时保持未知；需要生成文书但缺少决定文种、地区或程序分支的关键信息时，先补充这些信息再继续。

可以要求：

> 先比较两份材料的差异，不擅自选定其中一份为真实。保留已完成的索引，只更新付款对应关系，列出对结论有影响的未知项。

## 浏览器与电脑操作

### Chrome 中已登录，为什么助手还是看不到页面

内置浏览器和你日常使用的 Chrome 是不同入口，登录状态不会自动互通。需要使用自己的 Chrome 标签页时，按“设置 → Chrome 扩展”的说明安装并连接扩展，确认桥接状态，再指定希望操作的标签页。

不要为解决连接问题反复在不同页面输入账号密码。需要登录或验证码时，由你在对应网站完成必要操作；其他浏览器仅在当前客户端实际提供并连接成功时使用。

### 电脑控制不可用怎么办

先查看“设置 → 电脑操控”及当前设备提示，核对功能开关和系统权限。权限、系统版本或目标软件状态不同，会影响能否读取和操作。不要把浏览器扩展已经连接等同于所有桌面应用都可控制。

可先用不含敏感信息的页面测试读取、滚动与填写，确认正常后再处理获准的工作。详见[电脑与浏览器控制](/workflows/interactive-agents/03-computer-control-office)。

## 任务与定时安排

### 发现操作不对，如何停止和修改

使用任务中的停止控件，并明确下一步只修改哪些内容。停止后检查已经产生的文件和已完成的外部操作；停止不是撤销或回滚。要回退文件修改，应使用保留的工作副本或备份。

### 更换案件后，旧材料会自动隔离吗

应分别建立项目、任务和材料目录，并清楚指定本次范围。这是组织工作的方法，不是强制的文件访问隔离。新任务也不代表自动拥有上一任务的全部附件；需要复用时明确文件与来源，不让助手凭印象补写。

### 定时任务没有执行，先查什么

先在左侧“定时任务”中查看安排是否启用、计划时间和最近运行情况，再检查客户端运行、设备在线、账号及工具可用条件。不要把本地定时任务理解成不依赖本机的云端无人值守服务。

对法定期限，应另有人工登记与复核。具体创建、暂停和检查方式见[定时任务](/workflows/interactive-agents/05-scheduled-monitoring)。

## 计算与文书

### 同一案情为什么出现不同的金额

核对执行依据、本金、一般债务利息、加倍部分、费用，以及每笔付款的时间和抵扣规则。还要检查起算和截止边界、是否计入截止日、年计息基数、分配净款是否已经扣费。

不要只比较最后一行数字。要求列出公式、分段期间、天数和付款处理，然后用已确认口径重新计算。计算工具可复现某个口径，不代表该口径已经适用于本案。参见[计算说明](/workflows/execution-audit/08-interest-calculation)。

### 为什么调查令草稿不能直接生成

调查令需要地区、签发法院、程序阶段、具体调查对象和事项等关键信息。当前内置法院稿有地区母版限制，并非全国法院都能套用。不要为了通过生成校验改写真实地区或法院；可以先生成申请书或列明缺项。详见[调查令材料](/workflows/execution-audit/10-investigation-order)。

### 法律意见书为什么不是普通申请书的样式

法律意见书有专用工作流，默认区分咨询版与专业版；普通申请书、说明或法院工作稿应直接说明文种。需要 Word、PDF 或双格式时写清楚；正式使用前修改演示机构、Logo、出具人员及报价资料。参见[意见书交付](/workflows/document-delivery/11-legal-opinion-dual)。

### 怎样只改某一段

在原任务中说明文书名称、修改位置和确认内容，要求保留其他已确认事实与结构。对金额或主体的修改，仍应同步检查全文、表格、附件及主文中是否有对应内容。

> 请只修改申请事项第二项和出具日期，保持已确认的主体及事实不变。完成后重新生成 Word，并列出实际修改位置。

### 显示完成，却没有可打开的文件怎么办

对话中的正文或“已完成”描述不等于成品文件。要求提供实际文件入口，逐份打开检查格式和内容；记录具体是没有文件、链接打不开，还是文件内容不完整。连接、鉴权、生成或排版失败时，可保留已完成的研究结果，在原任务继续修复，不虚构下载链接。

准备提交前，再按[人工智能使用规范](/manual/03-supreme-court-ai-compliance)检查内容和辅助使用说明。
