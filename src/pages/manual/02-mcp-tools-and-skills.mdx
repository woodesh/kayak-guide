# 技能、工具与文档处理指南

通常不需要自己选择每个底层工具。说明任务、材料和交付要求后，助手可以调用已可用的文件、文档、浏览器和专业功能。遇到特定服务不可用时，再检查账号、扩展与授权。

## 插件、技能、连接器分别做什么

| 名称  | 用途                    | 使用方法                  |
| :-- | :-------------------- | :-------------------- |
| 插件  | 打包某类能力，可能包含技能、工具或服务连接 | 从侧栏“扩展”查看、安装或管理       |
| 技能  | 提供特定工作流程，例如文档制作或材料研究  | 说明目标，或明确要求使用已安装的相应技能  |
| 连接器 | 让助手访问某个外部服务或数据接口      | 安装后完成必要配置或账号授权，检查连接状态 |

安装成功不必然代表所有服务已经授权。部分连接器随插件统一管理，当前任务运行时的启停变更也可能等待任务结束后生效。使用前看实际状态，不在聊天里粘贴密钥。具体设置见[插件与连接器](/start/04-plugin-activation)。

## 读取 PDF、Word 与表格

文档读取支持 PDF、Office 文档以及部分 OpenDocument、RTF、EPUB 等格式。添加具体文件或指定本地路径，再说明要找的内容和需要的出处。

1. 先要求列出处理文件和检索范围。
2. 要求关键事实保留文件名、页码、段落或工作表位置；不能定位的地方明确说明。
3. 表格公式、批注、修订记录、图表和页面版式，需要专门检查，不能仅凭文字提取认定已经全部读到。
4. 扫描或模糊材料中的姓名、日期、金额、账号，回到原页核对。

```markdown
请查找这些合同、回单与聊天截图中涉及验收和剩余货款的记录。
按“主张—材料位置—记载内容—争议—待核对事项”整理。
疑似重复回单单独列明，找不到时说明检索过哪些文件，不把未找到写成没有发生。
```

读取扫描 PDF 或 Office 内嵌图片时，工具可能自动使用远程 OCR，不逐次询问。不允许上传时，在开始前明确要求“仅本地读取，禁止远程 OCR 和其他外部上传；不能读取的部分列明”。本地读取不是对模型全程离线的承诺；法院和单位材料仍应使用获准环境。

## 创建与修改办公成果

可以要求生成或修改可编辑 Word、Excel、PDF 和演示材料，并指定保存目录。聊天预览用于沟通，交付时应点击实际文件链接打开检查。

| 成果    | 提出要求时说清楚          | 打开后检查                |
| :---- | :---------------- | :------------------- |
| Word  | 文书类型、角色、格式、只改哪些段落 | 主体、案号、编号、附件、修订范围和分页  |
| Excel | 列项、去重规则、金额单位、计算口径 | 公式范围、文本账号、日期、汇总与重复交易 |
| PDF   | 使用目的、纸张、是否保留完整正文  | 内容完整、分页、字形与表格是否溢出    |
| PPT   | 听众、篇幅、来源及案例是否脱敏   | 图表数字、引用、可读性与敏感内容     |

让助手“保留公式”应指需要计算的单元格，原始数据和文字列无需都变成公式。重要数字应能回到材料与计算口径；格式整齐不代表事实已经核实。

```markdown
请把这些回单整理成付款明细 Excel：列日期、付款人、收款人、金额、流水号、对应合同与疑问。
相同交易只计一次，账号按文本保存；汇总保留可复核公式，注明金额单位。
保留原件，只在本案交付目录另存文件，并附实际文件链接。
```

没有文件、链接无法打开或只收到聊天表格时，要求助手核查保存位置并重新交付。需要保留旧版本时，明确另存文件名；文件保护安排见[数据与操作权限](/start/basics/07-security-boundary)。

## 法律研究、计算与专业文书

* **法律研究**：要求核对原文、适用时间与程序条件，比较类案事实差异，不为凑数量编造案例。见[法律检索示例](/start/basics/05-first-legal-task)。
* **金额核对**：提供本金、起止日期、计息依据、期间还款和抵扣口径；区分一般债务利息、加倍部分及费用，不以一个利率代替所有项目。
* **事实整理**：区分材料直接记载、单方陈述和未知事项；公开记录和模型摘要不能代替事实认定。
* **文书起草**：明确是申请人、律师还是法院角色，以及只要申请书、法院审查稿或其他文书；生成文件不等于签发或提交。
* **企业资料**：外部查询范围受服务和账号权益限制，关联关系不等于共同责任，也不能从公开企业记录推定银行余额。

具体业务方法应与对应章节配合使用，不把工具调用成功当成法律结论已经成立。

## 电脑操作、并行与定时任务

需要操作软件或已登录网页时，先完成相应启用和连接，明确“只填写，不提交、不发送”的范围。见[电脑与浏览器协同](/workflows/interactive-agents/03-computer-control-office)。

多个独立研究可提出并行处理，依赖前一步结果的工作按顺序推进，最后统一核对。复杂流程见[多步任务与并行协作](/workflows/interactive-agents/04-multi-step-workflows)。

按期检查材料可在侧栏“定时任务”创建，先试运行，再检查日程、状态和运行记录。见[定时任务操作](/workflows/interactive-agents/05-scheduled-monitoring)。

## 权限与中断

当前任务可能使用完全访问，文件写入、浏览器操作或外部查询不保证每次弹出确认。开始前核对权限、材料范围和外部传输规则，并明确保留原件、输出目录和禁止执行的动作。

发现错误时使用停止按钮，确认任务停止，再检查已有改动。停止不能撤回已上传的数据或自动还原全部文件；修订时说明采用哪份材料、只改哪里，并重新打开成果核对。
