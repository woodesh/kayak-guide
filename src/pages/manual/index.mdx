# 参考手册

任务进行到一半时，可以在这里查找提示词、工具条件、结果核对方法和故障处理。初次使用建议先完成[安装与准备](/start/02-installation-setup)和[账号与模型设置](/start/03-model-account)。

## 使用提示词示例

示例中的企业、金额、案号和材料都是任务输入的一部分。复制时替换为自己的真实情况，删掉不适用要求；材料未提供的字段保持未知。提示词不赋予浏览器、业务系统或第三方服务额外权限。

想了解一个任务怎样从材料推进到文件，查看[办案工作流](/workflows)；想比较具体输入和结果核对方法，查看[模拟案例](/recipes)。
