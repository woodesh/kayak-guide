# 操作示例：同步校对 Word 与付款表

一份情况说明引用了付款表的错误合计，需要更正数字，又要保留其他已经确认的段落。按以下示例先核对来源，再局部修改并取得 Word 与 Excel 文件。

## 准备四类示例材料

在同一案件项目中准备以下文件，原件和输出目录分开：

| 文件            | 示例内容                                   | 本次用途      |
| :------------ | :------------------------------------- | :-------- |
| 合同.pdf        | 合同价款500000元                            | 核对总价款     |
| 付款回单两份.pdf    | 实际两笔付款200000元和100000元                  | 核对逐笔交易    |
| 付款明细\_v1.xlsx | 三行记录为200000、100000、200000元，第三行重复第一笔流水号 | 排查重复合计    |
| 情况说明\_v1.docx | 原文称“已付50万元，剩余0元”                       | 更正引用的错误数字 |

另在任务中说明：“本例双方已经确认两笔付款均抵合同价款，除这两笔外无其他已确认付款；本次不计算利息、违约金或费用。”这是一项示例口径，不应由助手从回单自行推定。

## 第一步：先校对，不直接改文件

添加材料后发送：

```markdown
请先校对本任务中的情况说明Word、付款明细Excel、合同和回单，暂不改写文件。
1. 本例合同价款500000元；双方已确认两笔实际付款200000元和100000元，
   均抵合同价款，无其他已确认付款，本次不算利息、违约金和费用。
2. 按流水号、日期、金额和收付款人核对表格，识别疑似重复行，
   不仅凭金额相同就去重；说明每行对应哪份回单。
3. 核对Excel的明细、汇总公式和Word引用，列出“位置—原内容—建议—依据”。
4. 检查账号是否按文本保存，前导零是否完整；看不清的字符列待核对。
5. 不删除记录，不覆盖原件，不补写未提供的交易。
```

本例的核对目标是实际付款合计300000元、剩余合同价款200000元。若原表或回单与上述示例设定不符，应先说明差异，不强行得出预设数字。

## 第二步：确认修改范围，再同步更新

查看差异清单后，确认重复行确实对应同一笔交易，再追加：

```markdown
请按刚才确认的差异清单修改，保留全部原件：
1. Excel保留三行来源记录，新增重复标记和是否计入汇总栏，
   将已确认重复的第三行排除在本次付款汇总之外，不物理删除。
2. 已付款和剩余款项使用可复核公式；金额单位统一为元，账号保留文本格式。
3. Word仅修正付款合计、剩余价款和与此直接相关的表述，
   改为已付款30万元、剩余价款20万元，不变更其他已确认事实和文书用途。
4. 检查全文及表格是否仍有旧的50万元已付款、0元剩余款表述。
5. 在03_交付成果另存付款明细_v2.xlsx及情况说明_v2.docx，
   提供实际文件链接、保存位置和简短修订清单；不要发送给第三方。
```

原表可能有隐藏行、公式、批注或多个工作表，不能只提取文本后就声称已经全部校对。需要保留这些内容时应明确要求，并在 Excel 中打开检查；无法可靠保留的部分应报告，另存新版本供人工核对。

## 第三步：追加一处修改

再做一次局部修订练习：

> 请只把情况说明末尾的拟稿日期改为2026年10月21日，另存v3 Word。不要改变合同日期、付款日期、金额或附件；Excel不需要重做。完成后说明具体改了哪一处。

日期修改不应使助手把“拟稿日期”同步改成“签署日期”或历史事件日期。修订期间发现范围扩大，可使用停止按钮；停止不自动恢复先前文件，应打开各版本比较。

## 逐份验收实际文件

先打开 Excel，检查三行来源仍在、重复行未计入、汇总为300000元、余额为200000元，并点击计算单元格检查公式。再打开 Word，搜索旧数字及相关段落，核对主体、金额单位、附件和分页。v3 应只改变指定拟稿日期。

只有聊天中的表格或“完成”文字时，要求助手保存并提供真实文件入口；链接打不开时检查文件是否存在，再重新交付。本案例不给出虚构的下载链接。

任务可能使用完全访问，原件保护需要备份和明确的另存要求；扫描回单读取可能自动使用远程 OCR，不允许上传时应事先限制。进一步操作见[文档与工具指南](/manual/02-mcp-tools-and-skills)、[多步任务与局部修订](/workflows/interactive-agents/04-multi-step-workflows)及[材料整理](/workflows/case-prep/01-case-file-organization)。
