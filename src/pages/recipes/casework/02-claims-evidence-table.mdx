# 案例：主张、证据与时间线交叉核对

## 模拟目标与材料

测试甲公司主张设备已经交付、尚有货款未付；乙公司在沟通中提出交付迟延和质量异议。甲公司希望先整理主张对应的材料及矛盾，再判断需要补什么。本例只演示材料工作，不预设哪方主张成立。

本案目录共有7个文件，材料清单如下：

| 材料              | 本例设定及需要核对之处                  |
| --------------- | ---------------------------- |
| 盖章合同.pdf        | 1份，价款50万元，需读取具体交付、验收和付款条件    |
| 签收单.pdf         | 1份共2页，第一页写9月10日，第二页照片模糊      |
| 付款回单A.png、B.png | 2张，均显示20万元及相同流水号，需核对是否为同一交易  |
| 沟通记录.pdf        | 1份，其中9月12日消息写“设备还没到齐”，需保留上下文 |
| 质量通知.jpg        | 1张，署名、形成时间及对应设备尚待核对          |
| 接待记录.txt        | 1份，记载甲方关于交付和催款的陈述            |

本次未提供独立验收报告；签收单第二页则是已提供但尚未可靠读清。两种状态不能混写成“均无证据”，也不能反推没有验收或第二页没有内容。

## 可复制的首轮任务

```text
请只读取本案7个文件，保留原件，在工作副本中整理。
先做读取清单，分别标记已读且可定位、已提供但未读清、尚未提供。
围绕“是否按约交付、验收情况、付款用途、剩余价款及质量异议”
制作主张与证据对应Excel：列主张、需要证明的具体事项、材料与页码、
原文或片段、直接证明范围、可能反驳、矛盾和补强方向。
另建时间线工作表，记录事件日期、材料形成日期、来源和事实状态。
9月10日签收与9月12日消息并列核对，不替我挑选其中一份为真实。
两张20万元回单先检查是否同一交易，不重复扣款；未核明用途时保持待核。
在Word中简述主要争点与会影响判断的缺口，不把整理结果写成法院认定。
不为补齐表格编造日期、授权或材料；列明实际未读范围并交付可打开文件。
```

## 让矛盾对应具体问题

签收日期与沟通内容有差异，可以要求助手比较是否涉及分批交货、部分设备或记录日期不同；这些只是待核解释，不能未经材料支持选定其中一种。签收人身份不明时，列出需要核对的关系与授权材料，不直接认定签收无效。

证据表应能回到具体页面。接待记录记载的是当事人陈述，不能与合同、回单的直接记载混为同一种事实状态；文件标题也不能代替内容。

## 追加材料与修正时间线

后续取得清晰签收页和一份验收邮件，可以继续：

```text
新增清晰的签收单第二页和验收邮件。请替换原来“已提供未读清”的状态，
保留旧版本位置，更新受影响的交付、验收行和时间线节点。
我更正：接待记录中9月10日是装车日期，不是双方确认的到货日期。
把这项更正标为我的说明，再与原材料核对；不要无依据改掉签收单原文。
列出结论发生变化的地方，其余已经准确的行保持不变。
```

新材料可能支持或削弱原先判断。更新时应说明变化由哪份材料引起，尚未解决的矛盾继续保留，不用一条新记录覆盖全部旧证据。

## 成果与人工验收

应取得含读取清单、主张证据表和时间线的Excel，以及简明争点说明Word。人工抽查关键行能否找到原页、重复回单是否只计一次、金额单位是否统一；核对缺失材料、读取失败与证明不足是否分开。

最后检查时间线是否把陈述写成事实，Word是否与表格采用同一金额和日期口径。若要继续起草诉状或情况说明，再明确文种和使用角色。详见[主张与证据对应](/workflows/case-prep/07-claim-evidence-mapping)、[案卷整理与读取范围](/workflows/case-prep/01-case-file-organization)和[文书交付](/workflows/document-delivery/09-legal-documents)。
