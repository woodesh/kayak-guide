# 案例：两版合同审阅与修改对照

## 模拟目标与材料

测试甲公司准备采购一套设备。采购方发出V1草稿，供应商返回V2，甲公司希望先知道改了什么，再决定接受哪些修改。本例是模拟操作，不代表合同已经签订或某个条款必然无效。

将以下5份材料放入本案目录，保留原件，另建工作副本：

| 材料        | 本例设定及用途                       |
| --------- | ----------------------------- |
| 合同V1.docx | 采购方草稿，交付日9月30日，验收后30日付款       |
| 合同V2.docx | 供应商返回稿，交付日改为10月20日，付款改为发货前付清  |
| 报价单.pdf   | 价格与配置说明，需核对是否与两版合同一致          |
| 技术附件.xlsx | 设备规格、调试和验收项目，部分指标尚未确认         |
| 沟通摘录.txt  | 对方解释延期原因；甲方同事称“已经谈妥”，未附最终确认记录 |

“V2”文件名和同事的陈述都不能自动确定最终合意。纯条款比较可先使用这些材料，不必先做企业调查。

## 可复制的首轮任务

```text
我是采购方审核人员。请只处理本案目录，保留两版原件。
先列实际读到的文件与未读部分，比较合同V1和V2及报价、技术附件。
重点检查标的配置、价款、交付、验收、付款、违约和争议解决条款。
按“条款位置—V1原文—V2原文—变化—对我方影响—建议文本—待确认事项”
制作修改对照Excel，另给一份简明审阅意见Word。
区分文字变化、商业选择和需要核对依据的法律问题；引用时保留原文出处。
不要因文件名认定V2已生效，不把未确认的验收指标补成事实。
暂不覆盖合同，不代我确认条款，也不假设已经创建Word修订痕迹。
完成后提供实际生成文件的入口，不能生成时说明保留了哪些成果。
```

## 对照表先解决哪些问题

请助手把交付延期与付款提前放在一起审阅：两项变动怎样影响付款节点、验收材料和履行安排，而非只标记“日期改变”。技术附件仍有空项时，应列明空项影响哪个验收标准，不自行填写数值。

条款编号变化也要核对交叉引用。例如V2新增一条后，付款条款所引用的验收条款是否仍对应正确内容。无法可靠读取的表格或扫描页，应保留位置并列为待核。

## 追加材料与局部修正

收到经双方确认的邮件后，可以继续输入：

```text
新增“付款节点确认邮件.pdf”。邮件仅确认首付款30%，
余款条件仍在协商。请更新对照表的付款行及相关风险，其他已核对条款保留。
我方已决定接受10月20日交付，请将这项选择与尚未确认的付款条件分开。
先给建议文本供我审阅，不把邮件解释成接受V2全部内容。
```

确认采用的条款后，再要求生成另存的清洁稿，并附修改清单。清洁稿、修改对照表与Word原生修订痕迹是不同成果；需要修订痕迹时，应另行确认当前文档工具或办公软件是否支持，并打开文件核验。

## 成果与人工验收

应取得修改对照Excel和审阅意见Word；经确认后可再取得合同清洁稿。逐项打开检查：两版原文和位置是否正确，修改理由是否对应实际条款，报价与技术附件是否遗漏，已经接受和仍在协商的事项是否分开，原文件是否保留。

只有建议文字而没有实际文件时，继续要求制作对应文件，不把本页的示例文件名当成下载链接。方法见[版本比较与案卷整理](/workflows/case-prep/01-case-file-organization)、[普通文书制作](/workflows/document-delivery/09-legal-documents)；需要核对交易对象时，再按[企业查询](/workflows/execution-audit/13-qcc-enterprise-data)限定范围。
