# 案例5：股东变更、关联线索与追偿路径

## 示例案情

某供应链公司对某商贸公司有80万元执行债权，法院反馈存款仅几百元、未查到房产车辆。委托人怀疑原控制人王某转走业务或资金；怀疑需要核查，不能先写成恶意逃债事实。

为练习比较材料，另设以下示例记录：2025年8月发生欠款，11月发出催款函；12月5日登记股东、法定代表人由王某变更为72岁李某某。材料称王某原持股95%、认缴500万元、实缴10万元，认缴期限未届。12月20日王某与配偶新设某实业公司，经营范围相近；“承接原公司全部客户”仅为委托人陈述。

登记变化、出资信息、业务承接和资金去向应分别核查材料来源。

## 先查询具体问题，再研究法律路径

```text
请按本次80万元追偿目标核对商贸公司身份和近两年股东、法定代表人及资本变更。
保留来源、日期和具体关联路径；历史档案如需额外开通服务，说明缺口，
可先使用现有变更记录及我提供的材料，不承诺取得所有企业或全部资金去向。
将登记记录、委托人陈述与推测分别列出；经营范围相同不等于业务已经转移。
随后检索与本案主体变更追加、出资责任、实体诉讼有关的现行依据，
比较可用路径、证据、条件和救济，不先预定一定可以追加王某或关联公司。
最后生成研究说明Word及文件链接，不把尚未取得的银行流水写为已查明。
```

企查查需要自己的账号权益和相应查询配置；它提供的企业公开资料不等于银行账户余额或流水。查询范围见[企业数据](/workflows/execution-audit/13-qcc-enterprise-data)。

## 这些线索不能直接跳到责任结论

| 线索                | 可以进一步核查            | 不能直接认定               |
| ----------------- | ------------------ | -------------------- |
| 股东退出、代表人变更        | 时间、协议、出资期限及相关责任规则  | 变更就是逃债，退出即承担连带责任     |
| 认缴500万元、材料称实缴10万元 | 真实出资、履行期限、款项性质与证据  | 未出资490万元即为法院已确认可执行责任 |
| 新旧公司业务相近          | 人员、合同、账户、资产及客户实际流转 | 新公司资产属于旧公司或当然连带      |
| 存款少、无已查房车         | 已有调查范围、经营及其他财产线索   | 公司全部财产查清或已经满足所有追加条件  |

出资加速到期、股权转让责任、变更追加和法人人格责任需要分别研究，不能只把公司法与执行追加规定放在一起就推出“必然可直接追加”。程序申请与另行实体诉讼也要区分。

## 可交付与后续更新

### 把变更时间线重新画出来

本例适合先做“谁在什么时间发生什么变化”的底稿，再进入追偿研究。先按现有材料编排时间线，再依“拟核对来源”补充相应记录。

| 时间          | 示例记录              | 拟核对来源与状态              |
| ----------- | ----------------- | --------------------- |
| 2025年8月     | 发生80万元欠款          | 合同、交付和对账材料；发生经过仍需逐项对应 |
| 2025年11月    | 发出催款函             | 催款函及发送、送达记录；发出不自动等于收到 |
| 2025年12月5日  | 股东、法定代表人由王某变更为李某某 | 登记变更记录；转让协议、对价和出资情况另核 |
| 2025年12月20日 | 王某与配偶新设某实业公司      | 企业登记记录；经营相近不证明业务已转移   |
| 时间待核        | 委托人称新公司承接全部客户     | 暂为委托人陈述，需合同、往来及履行资料支持 |

关联关系也可以在底稿中这样分开表达：

```text
王某 ──原股东、原法定代表人── 原商贸公司
  └──与配偶新设── 某实业公司

原商贸公司 ···“客户转移”待核主张··· 某实业公司
            （不以虚线表示已证实的资金或资产流向）
```

### 分阶段取得成果，不一次预定责任

首轮只要求确认企业身份、变更记录及尚未取得的材料。记录来源、查询时间和权限状态后，再让执行事务研究不同责任路径，避免把企业信息查询摘要直接写成法律结论。

| 研究方向       | 应对应的材料问题           | 在研究说明中的表达               |
| ---------- | ------------------ | ----------------------- |
| 出资与股权转让    | 真实出资、期限、转让时间和相关证据  | 将登记记载与出资已核事实分开，列适用条件和缺口 |
| 人员、业务及账户关系 | 实际合同承接、履行、人员及资金资料  | 相似情况先列线索，不写成混同已经成立      |
| 程序选择       | 本次请求、主体、现阶段证据及适用依据 | 分别比较程序申请与实体诉讼，不预填一定追加成功 |

Word的示例阶段结论可以写：“现有底稿显示股东变更与新设企业时间接近，但尚不能据此确认资金转移、实际出资或责任成立。下一步材料按各研究方向分别补齐。”500万元与10万元的差额虽为490万元，也只是一项材料数字差额，不能据此写成法院已确认责任范围。

历史档案无权限、查询超时或结果为空时，应保留具体状态。后续收到出资凭证，可要求只更新出资行及相关研究，不把旧查询日期改成今天，也不把新材料自动写成法院已经采信；其余未解决的业务流转问题继续保留。

可交付企业变更时间线、关联路径、主张证据表和有来源的研究说明；需要实际追加申请书时再明确请求及责任范围，按[普通文书](/workflows/document-delivery/09-legal-documents)生成Word。

补充工商档案、出资凭证或调查反馈后更新受影响判断。本例演示追偿研究方法，办理结果仍取决于证据、适用法律与有权机关审查。
