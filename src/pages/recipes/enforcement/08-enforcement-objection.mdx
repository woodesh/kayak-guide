# 案例8：一台设备、两种异议，先辨主体与争议对象

## 模拟任务与材料

甲公司申请执行乙公司18万元货款债权，执行现场清单记载控制了一台编号M-07的数控设备。乙公司称设备价值远高于债务，质疑措施范围；案外人丙公司另称设备属于自己，只是出租给乙公司。两封材料都叫“执行异议申请”，但主体、请求和证明对象不同。

本例准备6组模拟材料：生效判决与履行记录、执行措施文书、现场清单及设备铭牌照片、乙公司书面意见、丙公司租赁合同和购货发票、送达凭证。发票设备编号能对应，租赁合同签署时间有争议；设备价值、剩余债务及实际送达时间还需核实。本页未实际检索案件或生成文件。

## 第一步：先得到程序辨别说明

```text
我是甲公司的代理人，请分别研究乙公司和丙公司的意见，不合并成一个异议。
乙质疑控制范围，丙主张自有设备权利；原文及请求见各自材料。
请核对提出人身份、争议对象、请求、当前阶段与相关程序依据，
比较可能的执行行为救济、实体权利救济及后续路径，结论保持与事实相符的条件。
期限按实际送达和适用原文核对，不凭文书日期猜收件日或预设统一天数。
分别列支持与反对理由、关键证据、待核事项，先不替任何一方确定最终请求。
交付程序辨别说明Word和主张证据表Excel，提供实际文件链接。
```

程序分流的操作重点见[执行实施与争议分析](/workflows/execution-audit/06-enforcement-analysis)。不要只看申请书标题，也不要因一方提异议就推定全部执行已经停止。

## 第二步：检查成果是否真正分清问题

| 对象     | 应得成果中的重点             | 核对点                      |
| ------ | -------------------- | ------------------------ |
| 乙公司    | 具体质疑哪项措施、范围或程序       | 债务数额、设备价值及现有材料是否足以比较     |
| 丙公司    | 主张什么权利、要求排除或改变什么措施   | 发票、合同、设备编号、占有与履行记录能支持到哪里 |
| 两方各自程序 | 资格、管辖、前置程序、期限起点及后续救济 | 每项判断对应实际查得的原文，未确认条件明确列出  |

两份申请共用同一设备，不表示同一事实已获双方认可。类案可帮助比较，不能补成本案缺少的租赁履行或价值认定。

## 第三步：追加材料，只更新受影响部分

```text
补充丙公司交接单和租金回单，设备编号仍为M-07；另补乙公司签收凭证。
请更新丙公司证据对应关系，以及乙公司期限起点的分析。
原有设备价值仍未知，不改写为已评估。保留其他已有依据的内容，
重新提供受影响的Word和Excel链接，注明这次更改对应哪份新材料。
```

需要实际异议、答复或其他申请书时，再确认制作主体和请求，按[普通法律文书](/workflows/document-delivery/09-legal-documents)生成。打开文件核对两方身份、设备编号、请求及日期，避免把研究中的可选路径写成法院已经作出的处理决定。
