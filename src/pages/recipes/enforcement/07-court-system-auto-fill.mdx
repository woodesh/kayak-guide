# 案例7：网上立案辅助填写与人工核对

## 模拟任务

周五16:30，律师准备在人民法院在线服务网页填报一宗跨地区货款纠纷：1名原告、3名共同被告（2家公司和1名自然人保证人），约28项主体、地址、诉请及附件信息。希望从已核对的Excel和Word填写页面，附件和正式提交由律师处理。

网站维护时间、页面字段和权限以实际页面为准；操作方式和耗时需依据当前页面确认。

## 操作前准备

将已确认的《立案当事人及诉请要素确认表.xlsx》和起诉状放在本案目录，标明原告、各被告及关联代理人；网页由本人按要求登录。需要使用已打开Chrome页面时，按设备提示连接浏览器扩展并指明目标标签页。

浏览器操作是根据实际页面执行，不表示已与法院系统专门接入；验证码、登录和权限仍由使用者处理。单位不允许相关材料进入当前环境时，不开展该操作。

## 把允许和停止范围写清

```text
请使用我当前Chrome中已打开的人民法院在线服务民事一审立案页面。
只按本案确认表填写原告及三名被告资料，按已确认起诉状填写诉请与事实理由。
本例诉请金额500000.00元，核对与确认表和起诉状一致，不引用其他案件判决金额。
附件位置只列拟用文件名，不上传；不要点击确认提交、完成立案或其他对外提交按钮。
未知字段留空并列出；页面跳转、出现声明或字段与资料不符时停止相关操作。
完成后列已填、未填与冲突项目，提供可用的页面核对信息，交由我检查。
```

“不要提交、不要上传”是这次任务的明确操作约束，不应称为已经验证的自动安全锁或技术上绝不可能越界。操作过程中发现异常可以立即叫停。

## 完成后怎样验收

| 项目      | 人工核对                        |
| ------- | --------------------------- |
| 主体对应    | 每个公司/个人身份、代码、法定代表人与代理关系是否串位 |
| 地址和联系方式 | 注册地址、经营地、送达地址各自归属，号码是否完整    |
| 诉请与金额   | 与本案起诉状一致，币种、小数、各项合计清楚       |
| 附件      | 文件版本、盖章件、分类和是否适合提交          |
| 操作状态    | 是否只是填写，是否实际上传或提交；以页面状态为准    |

实际填好才能报告已填；没有提交不能称为立案成功。页面截图和操作摘要也不代替最终受理凭证。由使用者核实附件及正式声明，按网站流程完成后续步骤，不以估计完成时间安排法律期限。
