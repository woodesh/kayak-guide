# 案例7：网上立案辅助填写与人工核对

## 示例任务

周五16:30，律师准备在人民法院在线服务网页填报一宗跨地区货款纠纷：1名原告、3名共同被告（2家公司和1名自然人保证人），约28项主体、地址、诉请及附件信息。希望从已核对的Excel和Word填写页面，附件和正式提交由律师处理。

网站维护时间、页面字段和权限以实际页面为准；操作方式和耗时需依据当前页面确认。

## 操作前准备

将已确认的《立案当事人及诉请要素确认表.xlsx》和起诉状放在本案目录，标明原告、各被告及关联代理人；网页由本人按要求登录。需要使用已打开Chrome页面时，按设备提示连接浏览器扩展并指明目标标签页。

浏览器操作是根据实际页面执行，不表示已与法院系统专门接入；验证码、登录和权限仍由使用者处理。单位不允许相关材料进入当前环境时，不开展该操作。

## 把允许和停止范围写清

```text
请使用我当前Chrome中已打开的人民法院在线服务民事一审立案页面。
只按本案确认表填写原告及三名被告资料，按已确认起诉状填写诉请与事实理由。
本例诉请金额500000.00元，核对与确认表和起诉状一致，不引用其他案件判决金额。
附件位置只列拟用文件名，不上传；不要点击确认提交、完成立案或其他对外提交按钮。
未知字段留空并列出；页面跳转、出现声明或字段与资料不符时停止相关操作。
完成后列已填、未填与冲突项目，提供可用的页面核对信息，交由我检查。
```

“不要提交、不要上传”是这次任务的明确操作约束，不应称为已经验证的自动安全锁或技术上绝不可能越界。操作过程中发现异常可以立即叫停。

## 完成后怎样验收

### 先做字段对应，再操作页面

在真正填写前，可以先让助手把确认表与网页字段对照，避免公司、自然人和代理人的信息串位。先形成字段对应表，栏目名称按实际网页核对：

| 本案信息       | 数据来源          | 写入页面前检查                  |
| ---------- | ------------- | ------------------------ |
| 原告         | 确认表中的原告一栏     | 名称、信用代码、地址分别对应，不复制被告资料   |
| 两名公司被告     | 确认表中各自的被告栏    | 法定代表人与公司归属一致，区分注册地址和送达地址 |
| 自然人保证人     | 确认表中第三名被告栏    | 按已确认身份资料填写，不从公司联系人推定身份   |
| 诉请与事实理由    | 本次已确认的起诉状     | 保持本案文本，网页分栏时核对是否截断       |
| 500000.00元 | 确认表及起诉状中的本例金额 | 币种、小数位及各项合计一致；不引用另一案判决金额 |
| 附件         | 本案拟用文件清单      | 只对应文件名、用途与版本，本轮不上传       |

字段对应有冲突时，可以先完成不受影响的核对工作，把争议字段列出来；不要为了填满表单猜测身份证号、地址或电话号码。

### 分阶段操作示例

按“确认页面—分段填写—复核结果”推进，并在每段记录实际观察到的状态。

```text
阶段一：识别目标页面
核对目标标签页、民事一审立案入口及当前登录状态。
对照页面实际字段与本案资料，先列未找到或含义不一致的栏目。

阶段二：按主体逐组填写
原告 → 两家公司被告 → 自然人保证人 → 诉请与金额。
每组填后核对所属主体；未知字段保留并记入未填清单。
如出现页面跳转、声明、验证码或字段冲突，停止相关操作并说明位置。

阶段三：停在本次约定范围
逐项记录实际已填、未填和冲突字段。
列出拟用附件，不上传，不点击对外提交按钮。
向使用者提供可用的页面核对信息，说明页面停留位置和实际操作状态。
```

如果发现网页要求先确认声明才能继续，不把该声明当作普通填空处理；先报告卡在何处以及已填哪些项目。尚未观察到的字段不能列为已完成，页面操作失败也不能用预期状态替代。

### 缺项与更正也要留下记录

可以要求一份示例格式的汇报表，实际操作时再填写真实结果：

| 状态栏   | 应报告什么                      |
| ----- | -------------------------- |
| 已填    | 对应主体、栏目、数据来源，以及可用的核对位置     |
| 未填    | 缺少的资料或尚未定位到的字段，不将空白猜成“不适用” |
| 冲突    | 页面与确认表哪里不同，哪些操作因此停止        |
| 附件与提交 | 是否实际发生上传、是否点击过提交，以观察到的状态为准 |

例如补来一个联系电话后，可以说：“只更新被告二联系电话，仍按原约定不上传、不提交；完成后重新核对该主体，其他字段不改。”如果页面已经跳转或保存状态不明，应先重新读取当前页面，不能盲目重复填入。人工验收发现误填时先修正对应栏目，再检查关联字段和主体归属，避免只改一处表面文字。

| 项目      | 人工核对                        |
| ------- | --------------------------- |
| 主体对应    | 每个公司/个人身份、代码、法定代表人与代理关系是否串位 |
| 地址和联系方式 | 注册地址、经营地、送达地址各自归属，号码是否完整    |
| 诉请与金额   | 与本案起诉状一致，币种、小数、各项合计清楚       |
| 附件      | 文件版本、盖章件、分类和是否适合提交          |
| 操作状态    | 是否只是填写，是否实际上传或提交；以页面状态为准    |

实际填好才能报告已填；没有提交不能称为立案成功。页面截图和操作摘要也不代替最终受理凭证。由使用者核实附件及正式声明，按网站流程完成后续步骤，不以估计完成时间安排法律期限。
