# 案例6：建筑工程纠纷的双版意见书

## 模拟案情与读者

某大型建筑工程集团作为总包方，就未完工结算、停工、工程款优先受偿期限及挂靠/转包抗辩咨询。董事会拟决定继续垫资还是停工诉讼；希望简明材料不超过3页，法务团队另需深入分析版。

这些是任务需求，不代表已经具备作出停工、解除或优先受偿判断的全部事实。3页是本例明确的阅读偏好，不是意见书固定页数，也不能为压缩页数删掉重大风险。

## 同一事实底稿，分别起草

```text
请根据本案合同、工程量确认单和往来催告材料出具咨询版与专业版法律意见书，
两版均要Word和PDF，最终提供四份实际文件链接。
咨询版帮助董事会理解当前选择、必要理由、重大风险及下一步；
希望正文尽量不超过3页，内容不应因篇幅失真。
专业版深入分析停工/解除条件、工程款及违约金依据、优先受偿期限，
以及挂靠/转包抗辩与本案的对应关系，不预设结论或补造催告送达。
逐项核现行原文、起算事实和材料范围，不沿用旧稿未经核实的条号或引文。
事实、来源与未知事项两版一致；本次不附报价，不估计胜诉率和回款周期。
```

咨询版最多采用2个参考案例，不要求凑满；专业版按争点需要采用。两版分别起草，不能把同一正文换标签复制。规范引文、案例和结论仍需结合原始材料核对。

## 品牌与日期另行明确

本例演示可采用河南信行（开封）律师事务所资料、提供的 `xinhang_logo.png` 和深绿色 `#1B4D3E`。实际对外使用时应改为使用者真实机构、Logo及出具人员，不把演示身份当作本案委托或执业关系。

```text
请按我提供的真实机构资料配置本次意见书，Logo使用本案附件，主题色深绿。
保留现有版式，致送对象和拟出具日期按本次确认信息填写。
案件中的合同、付款、停工、催告日期各按原材料，不随出具日期改变。
```

机构配置可以保存复用；只换颜色或封面可沿用已审阅正文，不必重新检索。若明确还要报价，先提供已确认的本机构方案、服务类别与有依据的实际标的，仅咨询版另附页，专业版不附。

## 交付核对

| 对象    | 检查重点                          |
| ----- | ----------------------------- |
| 两版正文  | 事实状态、金额、起算条件与关键结论是否一致         |
| 法律研究  | 原文是否支持具体命题，是否混淆实体权利与程序路径      |
| 机构与落款 | 身份、人员、致送对象、日期是否为实际资料          |
| 四份文件  | 链接可打开，版本/格式命名清楚；Word与PDF页数可不同 |

本例展示任务写法和交付核对点，不作为实际办案效果记录。意见书有独立审阅环节，但不等于律师审签或正确性保证。完整用法见[双版意见书](/workflows/document-delivery/11-legal-opinion-dual)与[机构配置](/workflows/document-delivery/12-firm-branding-customization)。
