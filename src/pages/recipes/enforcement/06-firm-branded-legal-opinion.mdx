# 案例6：建筑工程纠纷的双版意见书

## 示例案情与读者

某大型建筑工程集团作为总包方，就未完工结算、停工、工程款优先受偿期限及挂靠/转包抗辩咨询。董事会拟决定继续垫资还是停工诉讼；希望简明材料不超过3页，法务团队另需深入分析版。

这些是任务需求，不代表已经具备作出停工、解除或优先受偿判断的全部事实。3页是本例明确的阅读偏好，不是意见书固定页数，也不能为压缩页数删掉重大风险。

## 同一事实底稿，分别起草

```text
请根据本案合同、工程量确认单和往来催告材料出具咨询版与专业版法律意见书，
两版均要Word和PDF，最终提供四份实际文件链接。
咨询版帮助董事会理解当前选择、必要理由、重大风险及下一步；
希望正文尽量不超过3页，内容不应因篇幅失真。
专业版深入分析停工/解除条件、工程款及违约金依据、优先受偿期限，
以及挂靠/转包抗辩与本案的对应关系，不预设结论或补造催告送达。
逐项核现行原文、起算事实和材料范围，不沿用旧稿未经核实的条号或引文。
事实、来源与未知事项两版一致；本次不附报价，不估计胜诉率和回款周期。
```

咨询版最多采用2个参考案例，不要求凑满；专业版按争点需要采用。两版分别起草，不能把同一正文换标签复制。规范引文、案例和结论仍需结合原始材料核对。

## 品牌与日期另行明确

本例演示可采用河南信行（开封）律师事务所资料、提供的 `xinhang_logo.png` 和深绿色 `#1B4D3E`。实际对外使用时应改为使用者真实机构、Logo及出具人员，不把演示身份当作本案委托或执业关系。

```text
请按我提供的真实机构资料配置本次意见书，Logo使用本案附件，主题色深绿。
保留现有版式，致送对象和拟出具日期按本次确认信息填写。
案件中的合同、付款、停工、催告日期各按原材料，不随出具日期改变。
```

机构配置可以保存复用；只换颜色或封面可沿用已审阅正文，不必重新检索。若明确还要报价，先提供已确认的本机构方案、服务类别与有依据的实际标的，仅咨询版另附页，专业版不附。

## 交付核对

### 先确定事实底稿，再让两版各自展开

可以先要求助手列一页材料清单，把合同条款、工程量确认和催告材料分别定位；无法读清或未提供的部分单列。底稿可以按以下结构整理，逐项注明材料位置与核对状态：

| 材料组        | 两版都要采用的核对口径       | 目前不能代填的内容          |
| ---------- | ----------------- | ------------------ |
| 工程合同及补充约定  | 付款、工期、停工和解除安排逐项定位 | 未提供的具体条款、付款日及已达成变更 |
| 工程量确认与结算材料 | 确认主体、范围、签署及金额依据   | 把未确认工程量直接写成确定应收款   |
| 催告及往来函件    | 发出、送达与回复分别记录      | 没有凭证的送达经过、对方已认可的事实 |

核对后再生成两版，读者应当能看见内容差异，而不只是两份文件名称不同。

### 双版正文成品示例

咨询版可以用一页“当前决策”把问题说清：

> 当前需要决定是否继续垫资、协商调整履行或提出停工、诉讼等方案。现阶段先核对付款节点、工程量确认、催告及送达记录，再判断各方案的条件和后果。本稿不把董事会拟作出的选择写成已经采取的行动，也不据现有摘要测算胜诉率或回款日期。

| 董事会关心的选择 | 意见书应回答的具体问题                   |
| -------- | ----------------------------- |
| 继续垫资     | 当前付款、资金安排与新增投入如何记录，哪些条件尚待商业确认 |
| 协商或调整履行  | 希望改变什么、是否已有对方确认，需保存哪些沟通记录     |
| 拟停工或诉讼   | 哪些合同事实、催告及法律条件尚未核清，需先完成哪些研究   |

专业版则可以保留审查对象框和分层论证结构：

```text
审查对象：本案停工及解除条件、工程结算、优先受偿期限和挂靠/转包争点
资料范围：本次实际读取的合同、工程量确认及往来材料，逐项列位置
事实状态：材料记载、委托人陈述、双方争议和未核事项分别列明

一、案件事实及资料范围
二、法律争点分析
  1. 停工、解除及合同履行安排
    (1) 实际取得的规范原文与条件
    (2) 本案对应材料、相反材料及尚缺事实
  2. 工程价款及优先受偿期限
    (1) 待核起算事件和材料来源
    (2) 不同事实条件对判断的影响
三、材料补充与后续行动
```

这里展示的是成品结构，不能用空目录冒充已经完成法律研究。每个论证段都应回到实际取得的原文和本案材料，保留不能确定的结论。

### 交付时看四份文件是否相互对应

示例命名可使用 `本案意见书_咨询版.docx`、`本案意见书_咨询版.pdf`、`本案意见书_专业版.docx`、`本案意见书_专业版.pdf`；Word用于修改，PDF用于检查版面，分别打开核对版本与内容。

若董事会要求更短，先压缩重复背景和表述，不删重大风险；只改主题色或封面时，明确沿用已审阅正文。发现Word与PDF金额不一致，应回到同一正文底稿修正并重新输出受影响文件，不能只修改展示截图。页数不同本身不等于内容缺失，应检查段落、表格和附件是否完整。

| 对象    | 检查重点                          |
| ----- | ----------------------------- |
| 两版正文  | 事实状态、金额、起算条件与关键结论是否一致         |
| 法律研究  | 原文是否支持具体命题，是否混淆实体权利与程序路径      |
| 机构与落款 | 身份、人员、致送对象、日期是否为实际资料          |
| 四份文件  | 链接可打开，版本/格式命名清楚；Word与PDF页数可不同 |

意见书有独立审阅环节，但不等于律师审签或正确性保证。完整用法见[双版意见书](/workflows/document-delivery/11-legal-opinion-dual)与[机构配置](/workflows/document-delivery/12-firm-branding-customization)。
