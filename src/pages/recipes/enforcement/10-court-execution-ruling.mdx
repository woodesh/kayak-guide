# 案例10：法院执行裁定审查稿，债务27万元与余额62万元分列

## 示例任务与材料

某法院办理甲公司申请执行乙公司的货款案件，示例执行案号为（2026）测执208号。题设中的法院已核对：判决本金36万元，已付款9万元全部抵本金，剩余本金27万元；执行通知已经送达，履行期限届满后该剩余本金未支付。银行2026年10月8日反馈账户余额62万元，但现有反馈未说明在先冻结和资金性质。利息、费用尚未核定。

本次材料包包括判决、付款凭证及抵本金确认记录、送达材料、银行反馈、人员信息表和拟采用办理意见。任务是根据已确定的范围起草内部审查稿，未实际查询账户或生成裁定，也未作出司法措施。

## 第一步：把事实和拟采用意见交代完整

```text
我以法院承办人员身份起草执行裁定内部审查稿，交付一份可编辑Word及文件链接。
法院名称、双方主体和人员按本案信息表，案号（2026）测执208号。
请以法院已确认的剩余本金270000元作为本次拟控制金额组织草稿，
判决本金360000元、已付款90000元全部抵本金的过程在事实段写清。
银行反馈余额620000元单独记载，不改成本案债权或拟控制金额。
利息费用未核定，不擅加、不写为零；在先冻结与资金性质仍未知，
保留其对后续办理的影响，不写成“无其他冻结”或“全部可供清偿”。
拟稿日期2026年10月18日，银行反馈日期仍为10月8日，不混用。
不制作签名印章，不宣称已经签发或采取措施。
```

本例拟控制金额是承办人员给出的示例起草条件，不是从账户余额自动推出的法律结论。需要先研究措施种类或范围时，另提出[执行实施分析](/workflows/execution-audit/06-enforcement-analysis)，不要让文书生成替代办理选择。

## 第二步：打开Word检查三组一致性

| 检查组   | 应当对应                             |
| ----- | -------------------------------- |
| 债务口径  | 36万元减9万元为27万元，事实段、理由和主文不出现不同剩余本金 |
| 财产口径  | 62万元为某时点余额，在先权利和可执行范围未知事项不被删掉    |
| 身份与日期 | 法院、案号、主体、职务、拟稿日和反馈日各自准确          |

法院稿仍受连接器和母版允许的角色、文种与模式限制；说明法院身份不会取得正式签发权限。若不能生成相应稿件，应报告实际状态。一般规则及流程见[法院办理与起草](/workflows/document-delivery/13-court-drafting)。

## 第三步：追加付款后局部更新

```text
补充法院已确认的2026年10月16日付款12000元，明确全部抵本金。
请将剩余本金和本次拟控制金额相应更新为258000元，
同步修改事实段、理由与主文中受影响的数字。银行10月8日余额不作为新余额更新。
利息、费用及在先冻结状态仍按原限定，其余确认事实和人员不改。
另存修订Word并提供文件链接，不覆盖原稿。
```

检查修订稿是否保留付款来源和时间，不把后来的付款倒写入较早银行反馈。取得文件后仍按本院流程审查、修改、审批和签发；格式完整、金额相符不等于案件已经办理完毕。普通文书的缺项与局部修改见[Word交付工作流](/workflows/document-delivery/09-legal-documents)。
