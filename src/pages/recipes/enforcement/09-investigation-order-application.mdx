# 案例9：调取仓库交接记录，先申请书再决定是否要法院稿

## 示例任务与材料

河南省新乡市某基层法院审理甲采购公司与乙设备公司的买卖合同纠纷，案件处于举证阶段。双方争议2026年8月12日交付的设备是否与合同型号一致，相关出库及交接记录由第三方丙仓储公司保管。甲的律师收到丙公司的书面回复，称其不能凭目前申请人材料直接提供记录，拟向法院申请调查令。

准备的示例材料包括：法院及案号信息、采购合同与设备清单、送货单照片、向仓库请求材料及书面回复、律师和律所信息、本次拟调查事项。逐项记录拟调查材料及用途，仓库回复按原文整理，不改写为拒绝履行法院协助义务。

## 第一步：只生成本次需要的申请书

```text
请根据附件起草律师调查令申请书，只要一份可编辑Word及实际文件链接，
不附法院稿或回执。案件在河南省新乡市，签发法院和案号按附件，处于审理举证阶段。
拟向丙仓储公司调取2026年8月12日该批设备的出库单及交接记录，
批次、合同号和设备编号按清单，用于核对本案交付型号及交接情况。
不能自行取得的原因以丙公司书面回复原文为限，不补造其他拒绝经过。
申请人、相对方、持令律师和律所按材料；未知但适用的信息保留位置。
调查事项如过于笼统或内置规则不适配，请说明具体缺口，不修改真实地区。
```

这里将范围限定到一批设备及其交接记录，不请求仓库全部客户资料。申请理由、证明目的和材料保管单位要能相互对应，生成申请书也不表示法院已经准许。

## 第二步：再决定文件数量

当前工具默认只生成申请书。内置法院调查令稿对应河南新乡配置，其他地区仅申请书可复用版式；是否准许、具体范围与期限仍须按受理法院现行要求核对。完整说明见[调查令申请与法院审查稿](/workflows/execution-audit/10-investigation-order)。

```text
申请书范围已经核对。本次还需要与同一事项对应的法院调查令审查稿Word，
不重复附申请书，不要回执。沿用本案真实法院、地区、主体和记录范围，
未知编号、有效期及法院联系人保留适用位置，不推定申请已经审批。
请提供新增文件的实际链接；若当前法院稿不适配，保留该限制。
```

只有当前文种和权限适配时才可取得新增稿件。自然语言说明法院身份不会切换机构授权，详见[法院办理与起草](/workflows/document-delivery/13-court-drafting)。

## 第三步：追加与局部更正

仓库后来确认应按“出库批次号”而非采购合同号检索，可继续说：

```text
新回复给出出库批次号CK-0812-03。请只更新两份稿件的记录定位信息，
保留日期、设备范围和证明目的，不扩大为全部库存或所有交易。
重新提供受影响文件链接，并核对申请书与法院稿描述一致。
```

应得成果是所请求数量的真实Word文件。打开检查法院、批次、日期、设备编号、持令人员及草稿标识；若后来核实实际法院不在新乡，应更正真实地区并重新评估适配，不能沿用原地区取得文件。
