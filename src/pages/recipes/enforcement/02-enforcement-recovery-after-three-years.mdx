# 案例2：终本三年后的账户线索与恢复申请

## 示例案情

河南省开封市某基层法院（2022）豫02民初某某号判决乙公司支付甲公司货款20万元及违约金，原执行案件于2023年6月终本。2026年9月，甲公司取得乙公司在工商银行郑州某支行开户的线索及一张1万元转账回单。当前余额、资金性质及其他财产未知，判决、终本裁定和回单均需对照原件。

该1万元是线索回单中的交易金额，不是已向甲公司还款或账户余额。申请人不知道有无足额资金，不等于账户无款，也不等于已查明可供执行财产。

## 先咨询，再起草申请书

```text
我是甲公司的代理人。请根据本次示例材料研究终本后恢复执行：
1. 分开判断2023年6月至2026年9月的时间间隔与财产条件；
2. 区分开户行、账号、回单记载与未知余额，说明法院核查方向；
3. 说明申请人可以提出的请求、材料准备和主要风险；
4. 随后生成恢复执行申请书Word，提供实际文件链接。
原执行案号按终本裁定，不用民事判决号代替执行案号，不补造恢复案号。
未确认的付款、余额、代理授权和银行拒绝调查经过不要写成事实。
```

法律研究的原文入口与判断重点见[执行分析：终本三年案例](/workflows/execution-audit/06-enforcement-analysis)。不要仅凭间隔三年否定申请，也不要以“有账号”直接承诺恢复。

## 申请书哪些部分要留住限定

| 部分      | 本例核对点                         |
| ------- | ----------------------------- |
| 主体与执行依据 | 公司全称、代理关系、判决号和原执行案号分别填写       |
| 请求      | 恢复及依法调查处理的请求，不能写成法院已核查或已采取措施  |
| 理由      | 线索取得时间、来源及回单记载，未知余额保持未知       |
| 金额      | 判决债权、已履行部分、利息费用分别核对，回单金额不代替债权 |
| 附件      | 只列实际提交或明确拟提交的材料，不补造凭证         |

## 调查令另看适配范围

### 先核清三组材料，再组织申请书

可以把任务分成两轮：首轮只检查原判决、原执行及终本材料、账户线索；核对清单后，再要求沿用同一底稿生成申请书。核对表可按以下结构整理：

| 材料         | 在本例中解决的问题            | 缺失时如何处理                 |
| ---------- | -------------------- | ----------------------- |
| 生效判决及履行材料  | 判决债权、已履行部分与仍需核算的金额   | 不把20万元判决本金直接写成当前全部未履行债务 |
| 原执行材料与终本裁定 | 原执行法院、执行案号、终本时间和程序状态 | 执行案号留待核对，不拿民初案号替代       |
| 账户线索及1万元回单 | 线索来源、交易记载和主体对应关系     | 余额、资金性质和可执行范围保持未知       |

首轮结束应能看出“什么由哪份材料支持”，而不是只得到一句可以申请。若原始文件打不开，可先记录客户陈述并列出缺口，不能说已经核对裁定原文。

### 恢复执行申请书成品示例

起草时保留事实限定，并用本案材料补齐方括号中的主体、案号和材料信息：

```text
恢复执行申请书（示例结构）

申请执行人：【按实际主体材料填写】
被执行人：【按实际主体材料填写】
原执行案号：【按终本裁定核对】

申请事项：
请求贵院结合所附材料审查恢复执行申请，
并依法核查所列账户线索及相应财产情况。

事实与理由：
本案判决记载货款本金20万元及违约金，原执行案件于2023年6月终本。
2026年9月，申请人取得工商银行郑州某支行账户线索及一张1万元交易回单。
回单的主体、日期和账号请见附件逐项对应说明。
目前尚不掌握账户余额及资金性质；1万元为回单交易金额，
不据此表述为被执行人已向申请人还款或账户现有余额。
原判决、履行情况及法律依据按实际核对结果补入。

拟附材料：【仅列实际具备或明确拟提交的文件】
申请人及日期：【按真实主体和拟提交信息填写】
```

第二轮可以追加：“请按刚才核对结果起草，保留原执行案号待补项，并在交付说明中列出仍需我核对的材料。”这样，文件中的事实、金额和附件不会脱离首轮清单。

若后续收到银行或法院反馈，应先标明反馈日期、范围及原文，再更新受影响段落；不能把后来的反馈倒写成2026年9月已经掌握的事实。文件生成失败时保留核对表和已有草稿，报告未取得Word，不把聊天正文当成文书已交付。

如果希望申请律师调查令，先说明真实地区、调查对象、具体事项、证明目的与不能自行取得的原因。当前内置法院稿对应河南新乡；本例开封案件不能靠修改地区生成新乡法院稿。可按真实地区请求申请书版式，是否准许及调查范围仍由受理法院依法审查，详见[调查令限制](/workflows/execution-audit/10-investigation-order)。

恢复申请和调查令材料各有适用条件，不能保证受理、签发或回款。本页示例供实际任务时参考；取得Word后先打开核对，再按办案流程使用。
