# 案例1：货款材料、凭证去重与证据目录

## 示例材料

河南测试甲商贸有限公司向郑州测试乙建筑工程有限公司追索设备货款。压缩包共有22个文件：3份不同阶段合同（未签字草稿、总价50万元盖章版、手写修改补充协议）、6张送货验收单拍照、8张网银回单截图、5段催款与质量异议聊天长截图。签收人身份、部分款项用途与合同版本适用仍需核对。

材料应按内容逐项核对，文件数量本身不能证明交付、验收或欠款已经成立。

## 一次说明范围和成果

```text
请只处理本案01_原始材料目录，保留原件，复制到02_工作副本再整理。
将22份文件按合同、交付验收、付款、争议分类，保留原文件位置与版本状态。
逐张提取8份回单的日期、流水号、收付款人、金额和用途，疑似重复列理由，
冲突或模糊字段保持待核，不删除原件。
以盖章合同50万元为待核对合同口径，核对补充协议是否影响价格或付款条件。
形成时间线、付款Excel和证据目录Word；证据目录列材料位置、证明范围与争议。
如材料显示案外人付款或签收权限不明，单列问题，不预设法律性质。
生成后提供实际文件链接。
```

## 去重怎样影响金额

另设一个已经确认的算例：两笔实际付款为20万元、10万元，另附同一20万元付款的重复凭证，则付款合计30万元、合同价款差额20万元。这个减法不表示本案8份回单全部核完，也不自动解决付款用途或价款变更争议。

| 记录         | 处理方法            | 必须核对                 |
| ---------- | --------------- | -------------------- |
| 同一流水号的两份截图 | 标为疑似重复，再核其他交易字段 | 日期、金额、账户有冲突时不能只凭一项排除 |
| 案外人付款      | 单列付款人与用途        | 是否代付本案债务、合同和往来如何记载   |
| 非法定代表人签收   | 保留签字和材料位置       | 是否有授权、职务或其他认可证据      |
| 质量异议聊天     | 与验收、维修等材料对应     | 时间、对象、完整上下文及实际处理     |

证据目录宜写“用于证明/材料记载”，不要在未经审查时直接写“合同已经生效”“全部验收合格”“仅欠20万元”。

## 取得文件与补充材料

### 从22份材料走到三类成果

先让助手列出读取清单，再核对付款，最后整理证据目录。工作底稿可按下面的结构整理：

| 材料组       | 数量 | 首轮需要留下的记录                  |
| --------- | -: | -------------------------- |
| 合同及补充协议   | 3份 | 原文件位置、签章状态、价格及付款条件的差异      |
| 交付验收单照片   | 6张 | 对应设备、日期、签字及不清晰位置；签收与验收分别核对 |
| 付款回单      | 8张 | 每张保留来源，交易字段与是否计入汇总分列       |
| 催款、质量异议聊天 | 5段 | 上下文、对应事项及与其他材料的矛盾          |

读取清单若少了文件，先补读并说明范围；不要在材料尚未齐备时把“22份已全部核清”写入报告。合同版本有冲突时，可先完成付款记录提取，把受影响的价款结论留作待核。

### 付款明细 Excel 成品示例

下面只沿用前述“两笔付款及一张重复凭证”的独立算例。为演示公式，假设已核明两笔均抵合同价款；它不替代本案8张回单的逐张审查。

| A：来源记录    | B：交易对应    | C：凭证金额（元） | D：已确认计入（1/0） | E：本次计入金额（元） |
| --------- | --------- | --------: | -----------: | ----------: |
| 回单A       | 第一笔付款     |    200000 |            1 |      200000 |
| 回单B       | 第二笔付款     |    100000 |            1 |      100000 |
| 回单A的另一张截图 | 与第一笔为同一交易 |    200000 |            0 |           0 |

若表头在第1行，E2使用 `=C2*D2`，向下填充到E4；汇总使用 `=SUM(E2:E4)`，结果300000元；差额使用 `=500000-SUM(E2:E4)`，结果200000元。重复来源行仍然保留，便于解释为什么凭证金额相加50万元、实际付款却只计30万元。

### 证据目录和时间线怎样接上

证据目录可以先形成以下示例样行，实际材料位置须替换为读取清单中的真实位置：

| 证据组     | 拟证明事项           | 仍需核对            |
| ------- | --------------- | --------------- |
| 合同与补充协议 | 双方记载的交易、价款和付款约定 | 哪一版本适用、补充条款是否成立 |
| 交付签收材料  | 相应设备的交付记载       | 签收人身份、是否等于约定验收  |
| 回单及去重明细 | 已识别交易及其金额       | 付款用途、案外人代付依据    |

时间线每一行同时保留“事件日期、材料形成日期、来源位置、事实状态”，聊天说法和合同记载并列，不替读者选定哪一份为真实。发现回单日期或账户冲突时，先将相关行改为待核，暂停把它排除；补入清晰原图后，只重算受影响汇总，并同步更新Word里的金额表述。

应取得付款明细Excel、证据目录Word及相应链接；需要独立时间线文件可再明确格式。检查汇总公式、重复标记、文件位置及待核项。新回单或补充协议可在同案更新受影响行，不必全部重做。
