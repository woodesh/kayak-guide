# 案例1：货款材料、凭证去重与证据目录

## 模拟材料

河南测试甲商贸有限公司向郑州测试乙建筑工程有限公司追索设备货款。压缩包共有22个文件：3份不同阶段合同（未签字草稿、总价50万元盖章版、手写修改补充协议）、6张送货验收单拍照、8张网银回单截图、5段催款与质量异议聊天长截图。签收人身份、部分款项用途与合同版本适用仍需核对。

这不是一次真实诉讼验收；不能根据文件数就认定交付、验收或欠款已经成立。

## 一次说明范围和成果

```text
请只处理本案01_原始材料目录，保留原件，复制到02_工作副本再整理。
将22份文件按合同、交付验收、付款、争议分类，保留原文件位置与版本状态。
逐张提取8份回单的日期、流水号、收付款人、金额和用途，疑似重复列理由，
冲突或模糊字段保持待核，不删除原件。
以盖章合同50万元为待核对合同口径，核对补充协议是否影响价格或付款条件。
形成时间线、付款Excel和证据目录Word；证据目录列材料位置、证明范围与争议。
如材料显示案外人付款或签收权限不明，单列问题，不预设法律性质。
生成后提供实际文件链接。
```

## 去重怎样影响金额

另设一个已经确认的算例：两笔实际付款为20万元、10万元，另附同一20万元付款的重复凭证，则付款合计30万元、合同价款差额20万元。这个减法不表示本案8份回单全部核完，也不自动解决付款用途或价款变更争议。

| 记录         | 处理方法            | 必须核对                 |
| ---------- | --------------- | -------------------- |
| 同一流水号的两份截图 | 标为疑似重复，再核其他交易字段 | 日期、金额、账户有冲突时不能只凭一项排除 |
| 案外人付款      | 单列付款人与用途        | 是否代付本案债务、合同和往来如何记载   |
| 非法定代表人签收   | 保留签字和材料位置       | 是否有授权、职务或其他认可证据      |
| 质量异议聊天     | 与验收、维修等材料对应     | 时间、对象、完整上下文及实际处理     |

证据目录宜写“用于证明/材料记载”，不要在未经审查时直接写“合同已经生效”“全部验收合格”“仅欠20万元”。

## 取得文件与补充材料

应取得付款明细Excel、证据目录Word及相应链接；需要独立时间线文件可再明确格式。检查汇总公式、重复标记、文件位置及待核项。新回单或补充协议可在同案更新受影响行，不必全部重做。
