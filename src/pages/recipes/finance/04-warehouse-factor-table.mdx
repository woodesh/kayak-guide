# 案例4：仓储园区资料与要素式调查表

## 示例案情

甲公司申请执行乙公司的租赁合同债权。甲公司称，乙公司虽未查到房产、车辆，但运营物流仓储园区。甲提供8张商户缴费回单，账面合计12万元；本例中5张显示商户向乙公司付款，另3张收款人为案外人丙公司。完整租户数量、月收入、丙公司的开户行及当前余额未知。

本例的“收款人不同”与其他教程里“付款人不同”是不同题设，不能互换。丙公司是否关联、款项是否属于乙公司及能否执行，都还需要材料和法律分析。

## 生成目标与输入

```text
请将本例资料整理成《多主体调查资料补充表》，提供可编辑Word及实际文件链接。
保留完整陈述、核查对象、调查事项、期间、银行账户、关联案件和拟提交材料栏目。
按2026年9月1日至9月30日为本次拟核查期间，不写成已经完成的调查。
8份回单合计120000元仅为账面记录；5份收款人为乙、3份为丙分别列明。
未知开户行、完整收入与余额保留适用空栏，不填零，不补造案号和代理关系。
示例账号0012345678901234按文本保留前导零，并注明它对应哪份材料和主体。
```

## 栏目示例：不是已经生成的文件

| 栏目      | 本例适合记录的内容                      |
| ------- | ------------------------------ |
| 完整陈述    | 资料来源、8份回单、12万元账面合计、收款主体差异及未知事项 |
| 核查对象    | 乙公司、丙公司、园区各自角色；不能合并为同一主体       |
| 核查期间    | 本次要求的2026年9月，不等于账户已调取完毕        |
| 账户与金额   | 已知账号、开户名分别填；未知开户行/余额留空         |
| 关联案号与状态 | 仅写本案实际已提供信息，未知不沿用示例“执恢”号       |
| 材料清单    | 实际8份回单及其目录；拟提交和已经提交分开          |

不要在表格中一边写“案号未知”，一边自动填写其他示例案号；没有第二申请人或律师授权资料时，也不能为对称增加签署人。

## 收到文件后检查

### 先做回单清单，再填调查表

不要直接把8张图片拼进文书。第一轮先逐张列出原文件位置、付款人、收款人、日期、金额及可读账号，再核对5张与3张的主体分组。以下为示例清单摘要，不是本次已经识别出的交易结果：

| 分组      | 张数 | 金额处理                 | 应保留的问题           |
| ------- | -: | -------------------- | ---------------- |
| 收款人为乙公司 |  5 | 逐张提取后汇总，当前未给分组金额     | 是否与本案园区、期间和合同对应  |
| 收款人为丙公司 |  3 | 同上，不按张数估算金额          | 丙的角色及款项归属尚未确定    |
| 材料账面合计  |  8 | 题设为120000元，仍需与逐张明细核对 | 不代表完整园区收入或任何时点余额 |

若清单汇总与12万元不符，应展示差额及对应文件，先处理重复、漏读或金额识别问题，不能为了凑齐题设改动回单数字。

### 完整要素表的示例样式

下表展示Word里应保留的层次和空栏。未知信息用说明或适用空栏表达，签署区按真实主体补齐；它不是已经提交法院的文书。

| 多主体调查资料补充表（示例） | 内容                                                                                 |
| -------------- | ---------------------------------------------------------------------------------- |
| 完整陈述           | 甲公司就乙公司租赁合同债权提供仓储园区商户缴费回单8张，账面合计12万元；5张收款人为乙、3张为丙。完整租户、月收入、丙的开户行及余额未知，现整理拟核查事项供审查。 |
| 核查对象一          | 乙公司；题设中的被执行人，园区经营情况仍按材料核对                                                          |
| 核查对象二          | 丙公司；3张回单所载收款人，与乙的关系及款项归属待核                                                         |
| 园区信息           | 物流仓储园区的名称、地址按实际材料补入，不把园区名称自动当作企业名称                                                 |
| 拟核查事项          | 本次期间内与园区有关的缴费记录、收款主体及对应依据；具体范围供受理机关审查                                              |
| 拟核查期间          | 2026年9月1日至9月30日，不表示已取得该期间全部记录                                                      |
| 银行账户           | 分别填写回单能够支持的账号、开户名及来源；未对应到具体主体的账号不混填                                                |
| 开户行、余额         | 适用但未知的栏位留空，并注明待补；不填写0或猜测支行                                                         |
| 金额说明           | 120000元仅为题设8张回单账面合计；分组金额及完整收入待核                                                    |
| 关联案号、执行状态      | 按本案实际材料填写；题设未提供的内容保留待补                                                             |
| 拟提交材料          | 实际8张回单及逐张清单；文件名称、份数、原件位置按现有材料列明                                                    |
| 签署区            | 申请人、代理人及日期按真实材料设置；无第二申请人则不增设第二签署人                                                  |

演示账号 `0012345678901234` 只用于检查文本格式与前导零。实操中，只有核对到对应回单及开户名后，才将真实账号写入相应主体栏，不能把同一个示例号复制给乙、丙两家公司。

后续补来开户行信息时，可以追加：“请仅更新该回单对应主体的开户行和材料来源，不改其他主体的空栏，也不把已知开户行扩写成余额已查明。”重新打开Word核对表格是否跨页错位、完整陈述是否被截短，以及金额和未知状态是否在正文、表格中一致。

打开Word检查完整陈述是否保留、主体与账户是否对应、前导零和币种是否正确，金额是否仍限定为账面合计。只修改一项时指出栏目和新材料，再生成受影响文件。

要素表是调查参考，不会直接发起法院查控或冻结，不证明12万元收入属实，也不消除申请人核实材料的责任。后续可继续做[证据对应](/workflows/case-prep/07-claim-evidence-mapping)或[执行分析](/workflows/execution-audit/06-enforcement-analysis)。
