# 案例3：拍卖净款、利息与分配前提

## 模拟题设和需要先发现的缺口

商业用房拍卖后，扣除拍卖佣金与评估费的实到账可分配净款为120万元。债权人A银行称有第一顺位抵押，本金70万元、一般利息5万元；B甲公司为普通货款债权，本金40万元、履行期届满日2024年1月1日，题设另给“迟延1000天”；C乙商行为普通借款债权，本金20万元、届满日2024年6月1日，另给“迟延850天”。另列诉讼、执行及评估等费用合计2.5万元，需在3天内准备计算说明。

这组信息不能直接生成确定分配结论：债务人类型、适用程序、各债权资格、费用明细与是否已扣、真实停止事件和统一截止日均未完整提供。题设的两个天数也需与实际起止事件核对，不能因已给天数就视为合法计息期间。

## 先核费用、日期和分配规则

```text
请核对本例120万元净款与债权清单，先列事实缺口：
1. 120万元已扣拍卖佣金及评估费，2.5万元中哪些已包含、哪些额外承担？
2. B、C的日期、题设天数、一般利息及停止事件是否可对应？
3. 债务人类型、适用程序、资格、优先范围和控制顺序是否已经确认？
在已有事实支持范围内计算，未知内容只列明确的条件方案。
本金、一般利息、加倍部分分别列，不把加倍利息当然并入普通本金池同比受偿。
完成后制作可复核公式的Excel和计算说明Word，交付实际文件链接。
```

迟延利息的规范、日期边界与计算输入见[金额计算工作流](/workflows/execution-audit/08-interest-calculation)。规范名称、文号和适用条件以原文核对，不将软件结果称作终局核定。

## 只展示可确认的算术

| 算术情景                            | 结果       | 不代表什么              |
| ------------------------------- | -------- | ------------------ |
| A本金70万元加一般利息5万元                 | 75万元     | 不独立证明75万元全部在抵押优先范围 |
| 明确假设B按40万元、日0.000175、1000天计算    | 7万元      | 不证明真实期间、基数或适用规则已核  |
| 明确假设C按20万元、日0.000175、850天计算     | 2.975万元  | 不等于已确认可与本金同顺位分配    |
| 明确假设2.5万元全为未含在净款中的额外费用、A75万元全优先 | 剩余42.5万元 | 不确定其余债权的程序、顺位和最终受偿 |

如果2.5万元含已在净款扣除的评估费，不能再全扣一次。不能用“费用优先债权”掩盖成本扣减，也不能用各债权的含加倍利息总额直接按比例推出法定方案。

## 交付后继续核对

Excel应分列事实来源、假设、基数、期间、费用、债权与顺位；Word说明采用哪些已确认条件、哪些结果暂不能确定。校验总分配款不超过实到账款、各方受偿与未受偿一致、尾差处理可复核。
