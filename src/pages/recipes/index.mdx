# 实战案例：从材料到交付

这里按实际工作目标整理了 17 个练习场景，覆盖案件准备、金额核对、执行救济、法院工作稿和日常跟进。每篇给出材料、可复制的任务、追加修改与成果核对方法，选一个接近当前工作的场景即可开始。

案例库按示例材料展示任务输入、操作过程和成品结构。实际使用时，替换案例中的主体、案号和数据，并根据本案材料与已开通服务开展工作。

## 开始练习与验收

1. 替换示例身份、日期、金额与目录，确认材料允许在当前环境处理；新任务不能凭空取得其他任务的附件。
2. 先提供工作副本与明确目标。复制提示后删掉不适用项，缺失内容保持未知，不把另一案例里的余额或代理关系带入本案。
3. 按篇内方法检查阶段成果，再补充材料或确认修改；对于对外提交、发送和签署，明确授权并按实际流程复核。
4. 需要 Word、Excel 或 PDF 时写清格式，取得实际文件链接并打开检查。示例页面没有预先生成的案件成品，聊天中的表格不等于附件已经交付。
