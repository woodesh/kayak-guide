# 法律检索与原文查阅

法律研究可以组合使用执行事务资料库和浏览器。资料库返回原文片段与来源，由当前模型结合本案分析；网页搜索用于寻找公开原文。检索命中、引用卡片和模型复核都不等于法律适用已经无误。

## 先说明争点与范围

```text
请查终本后恢复执行的条件和时效问题。本案在河南，
现只有开户行、账号及回单，余额未知。
优先核最高人民法院原文，并区分全国规范、河南地方资料与实务参考。
列明每份来源支持的命题、适用时间和本案仍需核查的事实。
需要案例时只采用能对应原文的案例，说明事实差异；没有可靠结果不凑数量。
```

法律工具通常联合查询综合法律资料库与执行专题资料库，不需要用户选择内部库名。法规、案例和证据可按目标分别检索；公共资料库的证据检索不会自动搜索你的私人案件目录。

## 原文至少核对这些项目

| 项目 | 核对内容                    |
| -- | ----------------------- |
| 身份 | 正式名称、发布主体、文号；不能凭搜索标题补全  |
| 时间 | 公布、施行、修改及个案适用时间；日期各自归属  |
| 正文 | 条号、前后款、例外和引用的其他条文       |
| 性质 | 法律、司法解释、其他规范、实务书或案例分别标明 |
| 适用 | 地域、程序阶段、提出人身份与要件是否对应    |
| 来源 | 能打开的原始链接、查阅日期或资料定位      |

最高人民法院发布的不同材料也有不同性质，不能把新闻、答问、实务书或案例一律称为司法解释。地方资料的适用范围要具体核对，不把一个省的处理办法直接全国化。

## 浏览器怎样配合

公开网页可使用内置浏览器。需要当前Chrome页面和登录状态时，打开“设置 → Chrome 扩展”，按提示下载、安装并连接扩展，再明确使用哪个页面。只有当前客户端实际提供Edge选项且成功连接时才使用Edge，不把Chrome扩展流程视为Edge支持保证。登录、验证码、付费或单位权限仍按网站和单位要求处理，不能因页面已打开就推定有全部访问权限。

```text
请打开最高人民法院公布的终本规定原文，核对第九条的完整内容、
文件名称、发布与施行日期；保留原始链接，不只依据搜索摘要。
如果网页无法打开，请说明已取得的资料和未核部分，不补造网址或条文。
```

例如终本规定可从[最高人民法院原文](https://www.court.gov.cn/fabu/xiangqing/30111.html)核查。不要在文书中使用 `court.gov.cn/...` 一类占位地址充作已经验证的出处。

## 类案与已有文书复核

类案应列来源、案号、法院、日期、关键事实、裁判理由和与本案的差异，缺失信息如实说明。书中转述与直接取得的裁判全文分开，不把同案材料充作相似案例。

```text
请复核这份意见的引文和论证：列出原文能支持的结论、遗漏的条件和事实跳跃。
只修正有依据的问题，保留已经准确的段落。无法核验的说明范围，
不把“没有找到”写成“规则不存在”或“事实未发生”。
```

正式提交AI辅助材料前的核实和说明要求，参见[合规使用手册](/manual/03-supreme-court-ai-compliance)。
