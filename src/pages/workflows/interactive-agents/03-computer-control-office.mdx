# 电脑操控与浏览器协同

电脑操控适合需要在已打开的软件或网页中点击、输入、滚动和选择文件的工作。直接读写 Word、Excel 或 PDF 时，通常可以先使用文档工具；需要确认实际界面或填写表单时，再启用电脑或浏览器操作。

## 先选择操作方式

| 需求                   | 操作方式        | 开始前检查         |
| :------------------- | :---------- | :------------ |
| 查公开规范、打开网页原文         | 内置浏览器       | 目标网址、网络及访问权限  |
| 使用已有 Chrome 标签页和登录状态 | Chrome 扩展连接 | 扩展已安装且本机桥接已连接 |
| 阅读或操作桌面办公软件          | 电脑操控        | 已启用功能及必要的系统权限 |

内置浏览器与日常 Chrome 的登录状态应分别检查。使用其他浏览器时，先确认客户端列出了相应浏览器且能够连接；不要把 Chrome 的安装步骤直接套到所有浏览器。

## 连接 Chrome 的具体步骤

1. 打开 Kayak“设置 → Chrome 扩展”，点击“下载扩展安装包”。
2. 解压 ZIP，得到 `Kayak-Chrome` 文件夹。macOS 可在 Finder 中双击解压；Windows 可右键选择“全部解压缩”。
3. 点击“打开扩展管理页”，或在 Chrome 地址栏输入 `chrome://extensions`。
4. 开启右上角“开发者模式”，点击“加载已解压的扩展程序”，选择 `Kayak-Chrome` 文件夹。
5. 点击 Chrome 工具栏中的 Kayak 图标，检查是否显示“本机桥接就绪”；回到 Kayak 检查连接状态。
6. 手动登录目标网站并打开需要的页面，再告诉助手：“请使用我已打开的 Chrome 标签页”，附上页面名称或网址。

“已安装”表示扩展存在，不等于已连接。未连接时先确认 Kayak 和 Chrome 都在运行、该浏览器资料中扩展已启用，再点击扩展图标重试。出现“可更新”时，按设置页重新获取安装包并更新扩展。

## 启用电脑操控

打开“设置 → 电脑操控”，检查当前设备可用的控制入口。macOS 按提示允许相关组件使用辅助功能和屏幕录制；修改后回到 Kayak 再试。Windows 的权限和可用控制方式与 macOS 不同，按本机设置完成启用，不照搬 macOS 权限路径。

先用一个脱敏文件或测试网页验证能否读取、点击和输入。无法读取窗口时，确认窗口已打开、未被权限提示遮挡，并检查系统权限。不要通过反复点击不明位置继续尝试。

## 示例：填写获准业务网页

先由使用者登录并打开页面，确认本单位允许在该环境处理相应材料，再发送：

```markdown
请使用我已打开的 Chrome 业务页面，只填写本任务提供的信息表：
1. 先核对页面名称和字段，再填写已经确认的主体、账号和金额。
2. 账号按文本保留前导零；不确定内容留空并列出原因。
3. 只允许使用我指定的附件，不上传其他文件。
4. 不提交、不发送、不付款、不签署；完成后列出已填写及仍空缺的栏目，供我复核。
5. 页面变化、权限不足或出现验证码时停止该操作并说明。
```

填写完成后，人工检查网页内容和附件，再按业务流程处理后续动作。这里的限制是明确给出的任务要求，不能替代网站权限或本单位审批。

## 中断与法院使用边界

发现目标页面或填写内容不符，使用任务中的停止按钮，确认已经停止，再检查页面已有改动。停止不会自动清空已填内容，也不能撤回已上传的材料。

浏览器可操作的范围受账号和网站规则限制。本指南不表示 Kayak 已接入法院案管、财产查控、送达或签章系统；文书生成也不会自动冻结、扣划、送达或签发。
