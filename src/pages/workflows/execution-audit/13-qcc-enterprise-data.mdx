# 企查查：企业查询与九类工作

企查查插件可用于核对交易对象、梳理关联路径、整理公开风险，并与实际合同和付款材料对照。它提供调查资料和整理方法，不能仅凭公开记录确定资产归属、债务责任或案件结果。

## 查询前先确认连接与范围

企业查询需要用户自己的企查查账号和 API Key，具体步骤见[插件连接说明](/start/04-plugin-activation)。Kayak 登录、执行事务服务授权和企查查权益分别管理；查询费用以企查查账号的实际权益与账单为准。

先提供企业全称或统一社会信用代码，说明本次交易、争议和需要核对的时间范围。同名企业或候选结果不一致时，先核对主体，不急于继续扩大调查。

默认连接包含企业信息、风险、人员、经营和知识产权相关服务。完整历史档案、法规、案例、标讯及文档解析是可选服务，不会全部自动开启。已有的变更记录也不等于已取得完整工商档案；权限不足时，可以结合已可用记录或你提供的材料继续整理。

使用前应确认查询和后续处理环境符合企查查及本单位要求。允许查企业，不等于允许把查询结果或案卷发送到任意外部模型、网盘或文书服务。

## 九类可以提出的任务

下表是任务方法，实际可查询字段、记录数量和时间覆盖以服务返回为准。无需每次依次完成九项。

| 工作       | 可以向 Kayak 提出的任务          | 交付时应保留什么             |
| -------- | ------------------------ | -------------------- |
| 企业主体核验   | 核对名称、统一社会信用代码、法定代表人及登记状态 | 主体匹配依据、来源和查询时间       |
| 股权与关联调查  | 梳理股东、主要人员、对外投资及具体关联路径    | 关联类型、层级和仍需核对的关系      |
| 历史变更整理   | 围绕签约、欠款、股东退出或更名整理事件时间线   | 记录时间与实际事件时间，以及档案覆盖范围 |
| 合同主体审查   | 结合企业身份、资质和实际合同提出条款核对建议   | 公开资料与合同原文各自支持的判断     |
| 债权追偿调查   | 整理公开涉诉、执行、破产、担保及有关财产线索   | 案号、阶段、程序状态及权利负担      |
| 付款凭证对账   | 按你提供的合同、流水和回单核对收付款与欠款    | 原始凭证、去重依据、已付未付与争议金额  |
| 劳动合规核查   | 将公开记录与劳动合同、工资及社保材料对照     | 查询线索和实际用工材料之间的差异     |
| 知识产权风险排查 | 核对具体商标、专利及相关争议记录         | 权利主体、状态、日期及待核对事项     |
| 资质与许可核验  | 核对本次业务所需许可、有效期和具体适用范围    | 许可记录与实际业务的对应关系       |

付款对账使用的是你提供的材料，不是企查查查询到的银行流水。纯材料对账可独立完成，无需企查查 Key；助手也不能仅凭一张回单证明交易全部真实或确定第三人代付关系。

## 模拟案例：关联记录如何用于追偿研究

甲公司拟向乙公司追索50万元。为演示整理方法，假设已有企业资料显示：乙公司与丙公司有共同股东；同一纠纷出现一审记录和后续执行记录；乙公司还发生过股东变更。这是模拟设定，不是一次实际企业查询。

可以要求 Kayak 先交付以下结果：

1. **主体与关联表**：列明乙、丙公司身份、共同股东及具体关联路径，避免把两家公司合为一个主体。
2. **案件记录表**：按案号、当事人、金额和程序阶段核对记录，不把同一50万元纠纷重复累加。
3. **变更时间线**：将股东变更与签约、履行、争议发生时间并列，说明哪些事项仍缺少材料。
4. **后续研究问题**：结合合同、履行和出资等具体证据，研究可能的请求及其条件；不从共同股东或股权变更直接得出责任结论。

需要文书时，可把已查记录与实际案卷交给执行事务继续分析并制作 Word。复用已有来源，不必重新进行无关的全景调查；生成报告也不等于相关记录已经法院认定。

## 输入示例

```text
请核对乙公司身份，并围绕这笔50万元货款做有限调查：

1. 核对企业名称、信用代码和登记状态；同名结果先消歧。
2. 梳理与丙公司的具体关联路径，以及签约前后相关股权变更。
3. 按案号和程序阶段核对涉诉、执行记录，标明疑似重复项。
4. 结合我提供的合同和回单，列出追偿中仍需核对的问题。
5. 提供一份Word调查说明，保留来源、查询时间和检索范围。

不要把关联方财产算作乙公司财产，不推定未知账户余额。
查询无记录、权限不足或服务失败时分别说明，不用猜测补齐。
```

查询结果的解读与使用见[企业调查的记录与使用边界](/workflows/execution-audit/14-enterprise-investigation-boundaries)。
