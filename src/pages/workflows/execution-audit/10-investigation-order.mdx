# 律师调查令申请与法院审查稿

先说明要哪份材料：仅申请书、申请书与法院审查稿，或仅单份法院审查稿。生成申请材料、法院审查稿与法院正式签发是不同状态，不能互相替代。

## 可要求的文件

| 请求             | 默认交付               | 注意事项             |
| -------------- | ------------------ | ---------------- |
| 生成律师调查令申请书     | 一份可编辑Word及文件链接     | 默认不附法院稿          |
| 申请书和供法院审查的调查令稿 | 按适配情况生成两份Word，各有链接 | 明确要求两份，仍需核对地域和事项 |
| 只要法院调查令审查稿     | 适配时一份法院稿Word       | 不搭配申请书，不具有签发效力   |
| 另要材料接收回执       | 明确要求后附空白回执         | 不是接收单位已经签收的证明    |

执行事务会自动选择相应生成入口，你不需要填写工具参数。调查令申请书和成套材料使用专用流程；单份法院稿使用普通文书入口。

## 当前地域限制

当前内置调查令法院稿配置对应**河南省新乡市**，不是全国通用的签发规则。其他地区仅生成申请书时可复用申请书版式，但不代表当地规则已核或一定准许；法院稿或两份套件不适配时可能无法生成，应保留真实地区并说明限制。

内置配置有一事一令、有效期及调查事项校验。这些是已收录规则的产品配置，不能直接当作全国法律结论。具体调查范围、持令人员、有效期和申请材料仍须核签发法院现行要求。

## 一次提供影响生成的关键事项

* 实际地区、签发法院、案件案号、程序类型与当前阶段。
* 申请人、相对方、律师和律所；已知证号与联系方式按材料填写。
* 接受调查的具体单位、具体主体或账号、材料名称和期间。
* 证明什么，以及客观不能自行取得的原因。
* 需要几份文件，是否另要空白回执，拟稿日期与已确认有效期。

材料不全可以先整理，但地区、调查对象或事项不明等关键缺项可能需要补充。不要把笼统“案件相关材料”当作明确范围，也不要把多个独立事项合成一令。

```text
本案在【真实地区、法院】，目前【审理/执行/终本后恢复】阶段，案号见附件。
请只生成律师调查令申请书Word，不附法院稿或回执。
申请人、相对方和持令律师资料按附件。
拟向【具体单位】调取【具体主体、材料与期间】，用于证明【事项】；
不能自行取得的原因是【事实及来源】。未知余额保持未知。
若内置规则不适配，请说明限制，不修改地区或编造拒绝调查经过。
生成成功后提供实际文件链接。
```

需要两份时将第一句改为“生成申请书和供法院审查的调查令稿”；法院使用者可说“只要法院审查稿”，同时明确调查范围与真实地区。

## 取得文件后核对什么

核对法院、案号、调查对象、账户、期间、持令人员与文件数量；未知但适用的栏目保留填写位置，已知日期不改成另一个事件日期。局部更正时指出具体文件与字段，复用原任务中已经确认的材料。

Kayak当前连接器不因你说“我是法院人员”而改变机构权限，不能正式签发调查令，也不会替银行调出流水或余额。实际调查须经有权机关审查、签发并依法实施。法院身份和其他文书参见[法院办理与起草](/workflows/document-delivery/13-court-drafting)。
