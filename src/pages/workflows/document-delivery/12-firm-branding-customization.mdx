# 机构品牌、封面与服务报价

法律意见书支持由助手保存和复用机构配置。配置主要作用于专用意见书排版，不应理解为所有法院文书、普通Word和整个客户端都被改成同一品牌样式。

## 默认资料与自有资料

没有自有配置时，当前意见书沿用河南信行（开封）律师事务所的演示资料，包括Logo、封面封底及默认出具人员。它们用于演示，不能代替你的真实机构和执业身份。更换机构后，不能继续套用信行律师或报价。

| 资料      | 建议提供什么                  |
| ------- | ----------------------- |
| 机构身份    | 准确全称、英文名称（如有）、默认出具人员    |
| 联系方式    | 实际地址、电话、邮箱等需要显示的内容      |
| Logo与封面 | 你有权使用的本地图片，说明保留或更换哪些资产  |
| 主题色     | 明确颜色或色值；例如深绿 `#1B4D3E`  |
| 本次文书信息  | 致送对象、审查对象、拟出具日期；与案件日期分开 |

```text
请把法律意见书配置为我所在机构的版本。
全称、默认出具人员和联系方式见附件，使用我提供的logo.png，
保留现有排版和封面结构，主题色改为深绿色#1B4D3E。
清除演示机构的身份、Logo与律师资料，不沿用演示价格。
请保存为本机后续可复用配置，并用本次意见书展示实际效果。
```

机构配置和可复用资产保存在本地插件包外，升级不覆盖。它不等于自动同步到所有设备或团队成员；换设备使用时应确认实际配置。品牌资产和本地路径不作为法律检索材料上传。

## 报价只采用已确认的本机构方案

提供自己的报价单、截图或明确原话，说明哪些方案实际采用。助手可整理、保存并在以后复用；保存配置不等于形成法律服务合同，价格也不是法定收费标准。

```text
本次请按附件中我已确认采用的报价方案保存配置。
服务类别是【民商诉讼代理/执行代理】，标的及其来源是【材料原句】。
只在咨询版另附服务报价页，专业版不附；没有依据的项目或金额保持空缺。
```

当前默认信行演示资料有其已有报价，只有明确要求报价才读取并附页。其他机构没有自己的已确认配置时，不套用信行价格。

民商诉讼与执行代理要分清：有判决债权不等于适用民商分段代理费，也不等于已经回款。风险代理涉及实际回款时不能以判决金额替代；标的、类别或价格不明确，可先交付意见书正文，不猜报价。

## 修改与检查

只调整主题色、Logo或封面时，可要求沿用本次已生成正文重新排版。更改机构、出具人员或报价时，核对两版封面、落款和咨询版报价页是否一致更新。

打开实际Word/PDF核对中文全称、Logo清晰度、致送对象、日期及文件页序。样式可复用不代表本次正文已经审查，视觉完整也不代表签名、印章或正式出具已经完成。
