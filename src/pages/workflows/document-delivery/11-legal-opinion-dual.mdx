# 法律意见书：咨询版与专业版

明确说“出具法律意见书”即可进入专用工作流。默认围绕同一案情提供咨询版与专业版，分别起草；只需其中一版时直接说明。仅继续咨询或粘贴聊天记录，不会自动要求制作意见书。

## 两版分别解决什么问题

| 比较项  | 咨询版                 | 专业版                   |
| ---- | ------------------- | --------------------- |
| 用途   | 接待咨询、理解案件方向和服务价值    | 对委托事项深入分析和交付          |
| 重点   | 核心判断、必要理由、重大风险、当前行动 | 事实与争点、规则适用、证据影响、方案与结论 |
| 参考案例 | 最多2个，不要求凑满          | 按问题需要采用，无固定数量         |
| 报价   | 明确要求且有已确认方案时另附页     | 不附报价页                 |
| 准确性  | 保留必要条件和不利因素         | 使用同一事实底稿及来源边界         |

咨询版不是省略重大风险的宣传材料，专业版也不是可以直接替代法院判断的文书。两版不能仅换标签复制同一正文，页数不作固定承诺。

## 默认格式和文件数量

| 你的要求       | 默认两版时的文件           |
| ---------- | ------------------ |
| 未指定格式      | 两份PDF              |
| 只要Word     | 两份可编辑Word          |
| Word与PDF都要 | 四份文件，每版各一份Word和PDF |
| 明确只要一版     | 按指定版本和格式生成         |

Word保留可编辑正文和基本结构，PDF用于固定版式展示，两者页数可能不同。最终应逐个提供实际成品链接；开始生成、得到草稿或完成审阅均不等于成品已交付。

## 操作示例：恢复执行咨询记录

甲公司称其对乙公司有20万元判决债权，2023年6月终本，2026年9月取得开户行和账号线索。余额未知，判决与终本裁定原件仍需核对。本轮意见应使用这组材料及其事实状态。

```text
请根据本次恢复执行咨询记录出具法律意见书，咨询版和专业版同时提供Word与PDF。
重点回答：时间与恢复条件、账户线索的价值、材料准备和下一步方向。
区分委托人陈述、材料记载与未知事项，不将线索写成已经查明的财产。
审查对象用简洁标题；致送对象、出具日期与机构资料按我提供的信息填写。
没有可靠案例就不凑数，不估计胜诉率或回款时间。
本次不附报价。请提供四份实际成品的文件链接。
```

材料不全仍可基于限定事实分析，不能把“未提供解除通知”写成“从未发出通知”。确有影响结论的关键缺口，应就近说明条件。已在同案取得的依据可继续复用，不必为两版重复发起相同研究。

## 成品示例：专业版封面与正文

专业版可用以下结构呈现审查对象、事实限定和编号层级。制作时采用本案材料和真实机构资料，并将适用来源与分析内容填入对应争点。

```text
关于终本后恢复申请与账户线索的法律意见书
（专业版）

审查对象：恢复申请的时间问题、账户线索价值及材料准备
致送对象：示例甲有限公司
出具机构：示例律师事务所
拟出具日期：2026年10月14日

一、委托事项与材料范围
1. 本次需要回答的问题
   (1) 终本后的时间间隔对本次申请有何影响。
   (2) 现有开户行、账号与回单能支持什么，仍缺少什么。
   (3) 本轮可以准备哪些材料和后续请求。
2. 已提供材料
   (1) 咨询记录：记载甲公司对乙公司有20万元判决债权的陈述。
   (2) 账户线索：本例记录有开户行、账号及近期回单，真实性仍待核对。
   (3) 判决与终本裁定原件：本轮尚未提供，应列入补充材料清单。

二、事实状态与意见边界
1. 已知信息的来源
   (1) 2023年6月终本、2026年9月取得线索，均先按本例咨询记录记载。
   (2) 本稿不将上述陈述直接改写为法院已经查明的事实。
2. 尚未确认的事项
   (1) 当前账户余额及资金性质未知。
   (2) 原执行案号、已付款和裁定具体内容须回到原材料核对。
   (3) 其他示例中的余额、已付款或剩余本金不作为本案事实。

三、争点分析
1. 时间问题
   (1) 《最高人民法院关于严格规范终结本次执行程序的规定（试行）》
       第九条规定终本后的恢复申请及法院核查要求，恢复申请不受申请执行
       时效期间限制。适用前应核对原裁定确属终结本次执行程序。
   (2) 若原裁定及程序状态与上述前提相符，不能仅凭间隔三年就否定本次
       恢复申请；是否具备相应财产条件，仍须另行核查。
2. 账户线索
   (1) 现有开户行、账号及回单可以作为继续核查的材料线索。其来源、
       收付款主体、日期和用途应与原始凭证逐项对应。
   (2) 账号存在或历史交易本身不能证明当前余额及资金性质。现阶段不将
       该线索写为已经查实的可供执行财产，相关情况仍需法院核查。
3. 材料准备与下一步
   (1) 补充核对生效法律文书、终本裁定、原执行案号、已付款明细及线索
       来源，形成能够回到原材料的位置清单。
   (2) 根据核对结果准备本轮申请及调查请求。调查方式和所需材料按案件
       与当地要求确定，不预设一定适用律师调查令。

四、结论与待核事项
本轮应分别判断时间间隔与财产条件。现有线索可用于继续核查和准备申请材料，
但余额及资金性质仍未知，不能据此保证恢复申请获准或实现回款。取得原文书、
补充付款记录或调查反馈后，应更新受影响的判断及申请内容。
```

使用上述恢复执行分析时，核对[终本规定第九条原文](https://www.court.gov.cn/fabu/xiangqing/30111.html)、原裁定和本案程序状态。

三级编号可用于区分章节、争点和论证步骤，但不要求每个小标题都机械凑满三层。审查对象宜短而明确；长案情放在正文，不把整段事实挤进封面标题。

咨询版可沿用同一事实底稿，改用“目前能判断什么、主要风险、需要补什么、下一步怎样做”组织阅读顺序。例如余额仍未知，就在相关建议旁说明，不能为通俗易读删掉这一条件。专业版则展开来源、适用条件和反向理由；两版的事实和关键结论应能逐项对照。

## 机构、审阅与后续修改

未设置自己的资料时，沿用信行演示机构、Logo及默认出具人员等信息。正式对外使用前请配置真实身份，见[机构品牌和报价](/workflows/document-delivery/12-firm-branding-customization)。

工作流有检索和独立审阅环节，最终在本地排版；模型审阅和程序校验不能保证每项事实或法律适用无误，也不代表律师审签。连接、审阅或排版失败时应说明实际状态，不把聊天正文冒充文件。

同案修改时指明版本、段落和新材料；只改封面、主题色等视觉内容可复用已有正文数据，不必重新分析案情。法律正文或事实更正则核对两版同一事项是否一致。文件生成后，仍需核对主体、日期、金额、引用与结论，并按用途完成审查和签署。
