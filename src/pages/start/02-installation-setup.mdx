# 客户端安装与案件目录

先安装与你的设备匹配的客户端，再为案件准备材料目录。目录用于区分案件、保留原件和查找成果；它不会自动成为助手只能访问的安全边界。

## 选择安装包

| 设备                  | 下载                                                                                          |
| ------------------- | ------------------------------------------------------------------------------------------- |
| macOS Apple Silicon | [ARM64 安装包](https://download-kayak.kuanshi.top/kayak/desktop/latest/Kayak-darwin-arm64.dmg) |
| macOS Intel         | [Intel 安装包](https://download-kayak.kuanshi.top/kayak/desktop/latest/Kayak-darwin-x64.dmg)   |
| Windows x64         | [Windows 安装包](https://download-kayak.kuanshi.top/kayak/desktop/latest/Kayak-win32-x64.exe)  |

macOS 与 Windows 可能独立更新，版本号不必相同。单位统一分发安装包时，优先按管理员提供的渠道安装；下载失败时确认网络和来源，不使用不明镜像。

## 安装与登录

### macOS

1. 在你获得的正式下载入口选择 Apple Silicon（ARM64）或 Intel 安装包。可在苹果菜单的“关于本机”中查看芯片或处理器。
2. 打开 DMG，将 Kayak 拖入“应用程序”，再从“应用程序”启动。
3. 点击客户端的“登录”，在打开的浏览器中完成账号登录与设备授权，再回到 Kayak。
4. 第一次需要电脑操控时，按提示授予相关组件的辅助功能、屏幕录制权限。普通文件处理可以先开始，不必为此预先启用所有电脑控制权限。

如系统阻止打开，先核对安装包来源和设备管理要求；不要下载来路不明的替代包或直接关闭系统安全保护。若浏览器没有打开，使用客户端提供的登录链接继续；登录完成仍无响应时，检查网络并重试。

### Windows

1. 下载 Windows x64 安装包，运行安装程序。
2. 按向导完成安装并启动 Kayak；单位管理的电脑应使用获准安装方式。
3. 点击“登录”，在浏览器完成授权，再回到客户端。
4. 需要电脑操控或浏览器连接时，再打开相应设置完成启用。

安装、联网被单位策略或安全软件拦截时，请核对下载来源并联系管理员。无需为了普通使用统一关闭防火墙或放开所有网络。

## 准备案件目录

推荐在文件管理器中新建一个案件文件夹：

```text
货款纠纷_甲公司与乙公司
├── 01_原始材料
│   ├── 合同.pdf
│   ├── 判决书.pdf
│   └── 银行回单.pdf
├── 02_工作副本
└── 03_交付成果
```

把收到的材料放在“原始材料”，把中间整理结果和可交付文件分开保存。需要只读保护时，另行使用操作系统或单位文件管理机制；文件夹名称含“原始材料”并不会自动阻止改写。

## 在 Kayak 中使用目录

1. 在侧栏“项目”区域使用添加入口，选择该案件的本地文件夹。
2. 在该项目中建立新任务，先说明角色、处理目标和允许访问的目录。
3. 只处理几份材料时，也可以直接点击“新任务”，通过输入区的添加文件入口选择具体文件，不必先建立项目。
4. 明确输出位置，例如“保留原件，只在本案的 02\_工作副本和 03\_交付成果中保存新文件”。

项目适合把同一目录的多次工作归在一起。同案延续工作可回到原任务补充材料；不同案件应另开任务并检查附件，避免沿用上一案事实。具体步骤见[桌面操作入门](/start/basics/00-desktop-quickstart)。

## 找不到文件时

先在 Finder 或资源管理器中确认文件仍在原位置，再向助手提供正确目录或重新添加附件。文件移到别处后，旧路径可能失效；任务列表中的记录也不代表文件已经备份。保留原始材料备份，并在收到成品后实际打开检查。
