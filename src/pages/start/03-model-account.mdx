# 登录、思考强度与账户额度

先登录 Kayak，即可在新建任务时根据案件复杂度调节思考强度。账号余额、插件连接和企查查权益分别管理；其中一项正常，不表示其他项目也已开通。

## 登录并授权当前设备

1. 打开 Kayak，点击“登录”。
2. 在打开的浏览器页面完成账号登录，并按页面提示授权当前设备。
3. 返回 Kayak，等待客户端显示已登录状态，再开始任务。

单位提供的账号按管理员指引使用；能否自行注册，以登录网页提供的方式为准。无需把密码、激活令牌或密钥发到聊天中。

如果提示账号已绑定其他设备，按页面完成设备替换和身份验证。更换设备不等于多台设备可以同时共用一个登录状态；不要以共用账号代替团队成员的独立授权。

## 任务中的思考强度调节

新建任务后，输入框上方提供**思考强度**下拉调节选项。

Kayak 采用专属的模型底座支持办案，输入框下拉菜单中仅提供**思考强度**调节（如常规思考与深度思考），无需切换模型：
- **常规思考**：适用于日常材料初步分类、简单纪要整理或快速格式转换；
- **深度思考**：适用于复杂的争议焦点推演、终本案件恢复执行审查、多笔款项冲抵与迟延利息精算，以及起草正式法律意见书，助手会在此模式下进行更充分的逻辑推导与证据交叉比对。

思考强度高不代表法条、事实和数字已经绝对核实。处理案卷时，仍应要求助手区分材料记载、当事人陈述和未知事项，保留法条与案例来源；重要结论和交付文件由承办人员最终复核把关。

> 材料较多时，先说明目录、争点和期望成果。扫描质量、文件数量及任务复杂程度会影响读取与处理，不宜承诺任意篇幅的案卷都能一次完整读完。

## 在用户中心查看余额和记录

点击客户端左下角账号菜单，选择“用户中心”，在浏览器中进入账户页面。

| 页面    | 可以查看或办理的事项                      |
| ----- | ------------------------------- |
| 概览    | 钱包余额、近期消耗和账号设备信息                |
| 钱包    | 当前余额、可用充值方式，以及“查看记录”中的充值订单和支付状态 |
| 用量    | 请求与退费记录、消耗趋势及模型消耗分布             |
| 客户端设备 | 当前账号的设备信息和相关管理入口                |

用量记录以页面实际列出的调用为准。一次案件任务可能包含多次模型或服务调用，也可能包含本地整理步骤，不能把每一句操作指令都理解成一笔独立收费项目。

## 额度不足时怎么办

进入“用户中心 → 钱包”，查看当前是否提供充值档位和支付方式。页面可充值时，核对金额后按提示付款；付款后以订单支付状态和余额更新为准。

如果页面显示尚未配置充值方式，或使用的是单位统一采购额度，请联系管理员确认补充方式。订阅套餐、价格、额度和有效期以当前页面或已确认的采购方案为准，本指南不固定列出套餐，也不承诺付款后必定在数秒内到账。

余额充足但仍无法调用某项功能时，应继续检查服务权限和连接状态。法律服务未授权、插件未连接、账号试用到期等问题，不能单靠充值解决。

## 区分 Kayak 账户与外部服务账号

| 项目            | 使用什么账号或凭据                           |
| ------------- | ----------------------------------- |
| Kayak 模型与账户页面 | 当前 Kayak 登录账号，按其额度及权限使用             |
| 执行事务的法律服务     | 通过当前 Kayak 登录状态连接，还需有相应服务权限         |
| 企查查企业查询       | 用户自己的企查查账号和 API Key，查询范围及费用以该账号权益为准 |
| 已登录的网站或其他外部应用 | 按对应网站、应用及单位要求完成授权                   |

企查查积分不足时，应在企查查账号中核对权益；给 Kayak 充值不会自动增加企查查积分。具体连接步骤见[执行事务与企查查插件](/start/04-plugin-activation)。
