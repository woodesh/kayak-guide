# 数据与操作权限

先明确哪些材料可以处理、哪些动作可以执行，再开始任务。文件夹、任务名称和提示词有助于限定工作，但不能替代操作系统权限、单位数据制度或人工审查。

## 查看当前任务权限

输入区的权限选项决定助手使用文件和工具的范围。当前版本在支持时会默认采用“完全访问”，已有明确选择时沿用相应设置。完全访问允许访问网络和电脑上的文件，不会因建立一个案件项目而自动收窄到该目录。

处理案卷前，查看当前权限并使用单位允许的配置。需要范围更小的环境时，先由管理员确认可用设置；不要把“一案一目录”当成已经实现的物理隔离，也不要假定每次写文件、查询或浏览网页都会弹出确认。

## 读取材料可能涉及网络传输

模型推理、联网检索、外部插件和连接器可能向相应服务传输内容。读取扫描 PDF 或 Office 内嵌图片时，文档工具可能自动使用远程 OCR，且不会逐次请求确认。

如果材料不能上传，应在任务开始前明确要求：

> 只允许本地读取，禁止远程 OCR、外部上传和联网查询。无法读取的页或图片列为未读取，不要改用外部服务。先说明可处理的范围。

这能限制相应读取工具的外传方式，并不证明当前模型部署完全离线。涉密或受严格限制的材料，只能在本单位批准的系统和流程中处理；未获准时，使用脱敏模拟内容研究通用问题。

账号密码、验证码、密钥和数字证书口令，不要粘贴到普通对话中。需要授权外部服务时，使用该服务的授权页面或专门配置入口。

## 保留原件需要明确安排

Kayak 具备修改、移动和保存文件的能力，不能承诺所有任务都“绝不覆盖”。开始前先备份原件，并明确要求：

> 保留原文件名称和位置，只在“02\_工作副本”处理，在“03\_交付成果”保存新文件；重名时另存版本，不覆盖原件。

需要强制只读时，另行设置操作系统或文档管理权限。交付时检查原件和成品位置，不以文件夹名称或助手口头说明代替核对。

## 业务网页与重要动作

给助手网页填写任务时，明确网站、窗口、字段和允许上传的附件。例如：“只填写，不提交、不发送、不付款、不签署；完成后列出已填写与空缺栏目。”这是本次操作范围，不能表述成产品对所有网站的自动拦截保证。

登录、验证码和必要身份核验由使用者完成。正式提交、付款、签署、送达及对外发送前，按单位或办案流程核对。能够操作网页不意味着系统已与 Kayak 集成，也不会扩大你的业务权限。

## 发现异常时

1. 使用任务的停止按钮，确认运行状态已停止。
2. 检查已经保存的文件和已经执行的网页操作。停止只能中断后续处理，不能撤回已发送的数据或自动还原所有修改。
3. 说明错误位置、应采用的材料和继续范围，要求助手另存修订版本。

同案可在原任务继续；不同案件另建任务，并重新核对附件。法院工作人员还须遵守院内材料、账号与审批边界，研究结果不能代替事实认定、程序决定或文书签发。
