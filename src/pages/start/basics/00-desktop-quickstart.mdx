# 桌面操作入门：任务、材料与成果

下面以“核对合同付款并生成 Excel”为例。准备一份模拟合同和两张回单即可；首次练习应使用脱敏材料。

## 1. 建立任务

点击左侧“新任务”，输入本次目标。你不需要寻找“法律工作区”开关。已有同案任务时，可从侧栏最近使用的任务中重新打开，继续补充材料。

给不同案件分别建立任务，并使用容易辨认的名称。例如“甲乙货款案—付款核对”，比“帮我看一下”更容易回找。任务归档用于收起历史记录；它不等于删除电脑上的材料和成品。

## 2. 添加文件或选择项目

* **几份材料**：使用输入区的添加文件入口，选取合同、回单或图片；添加后核对附件名称，再发送任务。
* **持续处理案件目录**：在侧栏“项目”区域添加本地文件夹，再在该项目中建立任务；告诉助手要读取哪些子目录、成果放在哪里。
* **后续新材料**：在原任务中添加新文件，并说明它补充或更正哪项事实、影响哪些成果。

不要仅提供“我电脑里的合同”这样的模糊位置。遇到添加失败，先确认文件能够在本机打开，缩小到几份具体文件重试；目录中的大量文件可先要求列清单，再按清单分批处理。

## 3. 先检查权限，再发送要求

查看输入区的权限选项。当前任务可能使用“完全访问”，这允许访问电脑文件和网络；案件目录的选择本身不会限制访问范围。处理单位材料时，先遵守本单位环境和数据规则。

读取扫描 PDF 或 Office 内嵌图片时，工具可能自动使用远程 OCR。禁止上传的材料，应在开始前明确“仅本地读取，禁止远程 OCR、联网查询和外部上传；无法读取的部分列出来”。本地读取也不等于模型推理全程离线；需要完全不外传时，应先确认部署环境获准。

```markdown
请只读取本任务添加的合同和两张回单，核对付款：
1. 列出合同价款、逐笔付款和剩余款项，疑似重复交易单独列明。
2. 保留收付款人、日期、流水号和原文件位置；账号按文本保存。
3. 保留原件，不移动、不覆盖；在本案“03_交付成果”另存 Excel。
4. 汇总使用可复核的公式，无法确认的对应关系标为待核对。
5. 不向外部网站上传或发送材料；需要新增处理方式时先说明。
```

若扫描件不允许远程识别，再补上“仅本地读取，禁止远程 OCR”。如无法识别，可由你先在获准工具中转成文字，再提供脱敏文本。

## 4. 看结果，打开实际文件

助手给出结果后，点击实际文件链接，打开 Excel、Word 或 PDF。检查文件名、保存位置和内容；聊天中的表格、图片预览或“已经完成”文字不能代替成品文件。

没有文件链接时，可直接说：“请把结果保存为可编辑 Excel，并给出实际文件链接及保存位置。”打开失败时，让助手检查文件是否仍存在并重新提供；表格还要检查账号前导零、公式和汇总范围。

## 5. 修改、停止与继续

只改一处时，指出文件和位置，例如：“只修正第二笔付款的日期，保留其他已确认内容，另存新版本。”修改完成后仍需打开新文件复核。

运行方向有误时，使用任务中的停止按钮，并观察状态是否已经停止。需要继续时再发送更正要求。发送“停止操作”也能表达意图，但需要立即中断时优先使用停止按钮。

停止不会自动撤销已经保存、上传或发送的内容。先核对操作记录和目标文件，再说明继续范围；已有准确结果可作为后续工作的基础，不必要求全部重做。

## 6. 两个常见延伸

* 多项工作：在同一任务说明最终成果，要求先列步骤；需要并行时，把互不依赖的研究范围说清楚，最后统一核对。见[复杂任务协同](/workflows/interactive-agents/04-multi-step-workflows)。
* 定时跟进：打开侧栏“定时任务”，让助手建立日程，核对目录、时间与运行状态，并先试运行。见[定时任务操作](/workflows/interactive-agents/05-scheduled-monitoring)。
