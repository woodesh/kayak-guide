# Kayak 法律助手实战指南

Kayak 是专为中国法律实务打造的智能桌面工作台，能够直接读写本地案卷、查阅权威司法法规、协助操作办公软件并输出符合审判执行规范的正式文书。本指南面向执业律师、企业法务及司法审判执行人员，全面介绍如何运用开箱内置的执行事务引擎与企查查企业大数据，高效完成案卷梳理、类案法规检索、加倍利息精算与规范文书起草。
