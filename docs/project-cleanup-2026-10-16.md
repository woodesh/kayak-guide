# Web 项目清理记录

本仓库是 Next.js / Nextra 文档网站。清理范围仅为 KayakGuide，不涉及相邻桌面客户端、new-api 或法律插件产品代码，也未执行 Vercel/Cloudflare 部署和 DNS 修改。

- 移出 238 个未引用的公开资源，约 87.3 MiB，包括旧 Ink 品牌 ZIP、PDF、视频、图标和未使用的示例截图；当前 `public` 保留 6 个文件，约 0.4 MiB。运行引用保留首页明暗两张图片及 Kayak 图标，另保留少量 Kayak 品牌源资产。
- 移出未被页面或配置引用的模板组件、区块链内容、钱包网络代码、旧图片与一次性迁移脚本；保留 Nextra 自动发现的 `_meta.ts`、仍使用的圆角配置、本地字体、Mermaid 适配和 ASCII 动画。
- 删除指向原模板团队的 GitHub 自动部署、安全工作流和 CODEOWNERS，避免把旧团队、旧 Vercel 项目标识及授权继承带到新仓库。未新增自动部署。
- 删除失效的 GitHub 占位配置、重复的旧 ESLint 配置和未使用的样式；本地工具目录、构建缓存及环境文件不进入源码提交或发布包。
- 统一使用 `NEXT_PUBLIC_SITE_URL`，域名未知时跳过 sitemap、删除旧生成物并省略 JSON-LD 的 URL；不再发布虚构的 `.local` 地址。配置方式见 README 与 `.env.example`。
- 所有移出的当前文件均在项目外保留可恢复副本和 SHA-256 清单；没有删除本机依赖或覆盖其他任务的修改。

现有 52 个 MDX 页面和 17 篇案例保留。验证包括生产构建与类型检查、全站 MDX、内部链接与导航、ESLint、针对改动文件的格式检查，以及未配置/非法/合法站点地址的 sitemap 处理。
